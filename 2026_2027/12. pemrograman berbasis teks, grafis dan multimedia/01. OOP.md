## 2. Minggu 1 — Review OOP Dasar

### Materi 1: Class dan Object

Class adalah cetak biru untuk membuat objek, sedangkan object adalah hasil instansiasi dari class.

Contoh: class `Mahasiswa` mendefinisikan data mahasiswa, sedangkan objek `mhs1` dan `mhs2` mewakili mahasiswa yang berbeda.

Buat file `minggu-01-oop-dasar/ClassObject.java`.

java
```
class Mahasiswa {
    String nama;
    String nim;

    void tampilkanData() {
        System.out.println("Nama: " + nama);
        System.out.println("NIM: " + nim);
    }
}

public class ClassObject {
    public static void main(String[] args) {
        Mahasiswa mhs1 = new Mahasiswa();

        mhs1.nama = "Andi";
        mhs1.nim = "231001";

        mhs1.tampilkanData();
    }
}
```

Output:

text
```
Nama: Andi
NIM: 231001
```

Hal yang perlu dipahami:

- Attribute: data yang dimiliki objek, seperti `nama` dan `nim`.
- Method: perilaku atau fungsi yang dimiliki objek, seperti `tampilkanData()`.
- Instantiation: proses membuat objek menggunakan `new`.

### Materi 2: Inheritance

Inheritance (pewarisan) memungkinkan sebuah class mewarisi atribut dan method dari class lain menggunakan kata kunci `extends`.

Hewan

Superclass / Parent

`makan()`

Kucing

Subclass

`meong()`

Anjing

Subclass

`menggonggong()`

Buat file `Inheritance.java`.

java
```
class Hewan {
    void makan() {
        System.out.println("Hewan sedang makan");
    }
}

class Kucing extends Hewan {
    void meong() {
        System.out.println("Meow!");
    }
}

public class Inheritance {
    public static void main(String[] args) {
        Kucing kucing = new Kucing();

        kucing.makan();
        kucing.meong();
    }
}
```

Output:

text
```
Hewan sedang makan
Meow!
```

Kesimpulan: objek `Kucing` bisa memanggil `makan()` karena method tersebut diwarisi dari class `Hewan`.

## 3. Minggu 2 — Pengenalan OOP Lanjutan

### Materi 3: Abstract Class

Abstract class adalah class yang tidak dapat dibuat objeknya secara langsung. Class ini digunakan sebagai dasar bagi class turunannya.

Abstract class dapat memiliki:

- Method abstrak yang belum memiliki implementasi.
- Method biasa yang sudah memiliki implementasi.
- Atribut dan constructor.

Contoh file `AbstractClass.java`:

java
```
abstract class Bentuk {
    abstract double hitungLuas();

    void tampilkanPesan() {
        System.out.println("Menghitung luas bentuk");
    }
}

class Persegi extends Bentuk {
    double sisi;

    Persegi(double sisi) {
        this.sisi = sisi;
    }

    @Override
    double hitungLuas() {
        return sisi * sisi;
    }
}

public class AbstractClass {
    public static void main(String[] args) {
        Bentuk bentuk = new Persegi(5);

        bentuk.tampilkanPesan();
        System.out.println(
            "Luas persegi: " + bentuk.hitungLuas()
        );
    }
}
```

Output:

text
```
Menghitung luas bentuk
Luas persegi: 25.0
```

Perhatikan bahwa `Bentuk` tidak dibuat langsung dengan `new Bentuk()`. Objek yang dibuat adalah `Persegi`, yang mengimplementasikan method abstrak `hitungLuas()`.

### Materi 4: Interface

Interface adalah kontrak yang menentukan perilaku yang harus disediakan oleh class yang mengimplementasikannya.

Interface menggunakan kata kunci `interface`, sedangkan class menggunakan `implements`.

Contoh file `InterfaceDemo.java`:

java
```
interface BisaBersuara {
    void bersuara();
}

class Kucing implements BisaBersuara {
    @Override
    public void bersuara() {
        System.out.println("Meow!");
    }
}

class Anjing implements BisaBersuara {
    @Override
    public void bersuara() {
        System.out.println("Guk guk!");
    }
}

public class InterfaceDemo {
    public static void main(String[] args) {
        BisaBersuara kucing = new Kucing();
        BisaBersuara anjing = new Anjing();

        kucing.bersuara();
        anjing.bersuara();
    }
}
```

Output:

text
```
Meow!
Guk guk!
```

Catatan: method abstrak yang dideklarasikan pada interface bersifat `public`, sehingga implementasinya juga harus `public`.

### Materi 5: Polymorphism

Polymorphism berarti satu tipe referensi dapat merepresentasikan berbagai objek dengan perilaku yang berbeda.

Contoh file `Polymorphism.java`:

java
```
abstract class Kendaraan {
    abstract void bergerak();
}

class Mobil extends Kendaraan {
    @Override
    void bergerak() {
        System.out.println("Mobil berjalan di jalan raya");
    }
}

class Kapal extends Kendaraan {
    @Override
    void bergerak() {
        System.out.println("Kapal berlayar di laut");
    }
}

public class Polymorphism {
    public static void main(String[] args) {
        Kendaraan[] kendaraan = {
            new Mobil(),
            new Kapal()
        };

        for (Kendaraan k : kendaraan) {
            k.bergerak();
        }
    }
}
```

Output:

text
```
Mobil berjalan di jalan raya
Kapal berlayar di laut
```

Method `bergerak()` dipanggil dengan cara yang sama, tetapi hasilnya berbeda sesuai dengan jenis objek yang digunakan. Ini merupakan contoh runtime polymorphism melalui method overriding.

## 4. Perbedaan Abstract Class, Interface, dan Inheritance

| Konsep | Fungsi | Kata kunci |
| --- | --- | --- |
| Class | Cetak biru objek | `class` |
| Object | Instansiasi dari class | `new` |
| Inheritance | Mewarisi class lain | `extends` |
| Abstract class | Dasar class yang dapat memiliki method abstrak dan konkret | `abstract` |
| Interface | Kontrak perilaku | `interface`, `implements` |
| Polymorphism | Satu referensi, berbagai perilaku objek | Overriding |

Perbedaan penting:

- Sebuah class Java hanya dapat mewarisi satu superclass langsung menggunakan `extends`.
- Sebuah class dapat mengimplementasikan lebih dari satu interface.
- Abstract class cocok untuk berbagi identitas, atribut, dan perilaku dasar yang berkaitan.
- Interface cocok untuk mendefinisikan kemampuan atau kontrak yang bisa diterapkan pada berbagai class.

### A. File `Pegawai.java`

java
```
public abstract class Pegawai {
    protected String nama;

    public Pegawai(String nama) {
        this.nama = nama;
    }

    public String getNama() {
        return nama;
    }

    public abstract double hitungGaji();
}
```

### B. File `Kontrak.java`

java
```
public interface Kontrak {
    void tampilkanStatusKontrak();
}
```

### C. File `PegawaiTetap.java`

java
```
public class PegawaiTetap extends Pegawai
        implements Kontrak {

    private double gajiBulanan;

    public PegawaiTetap(String nama, double gajiBulanan) {
        super(nama);
        this.gajiBulanan = gajiBulanan;
    }

    @Override
    public double hitungGaji() {
        return gajiBulanan;
    }

    @Override
    public void tampilkanStatusKontrak() {
        System.out.println("Status: Pegawai Tetap");
    }
}
```

### D. File `PegawaiFreelance.java`

java
```
public class PegawaiFreelance extends Pegawai
        implements Kontrak {

    private int jumlahJam;
    private double tarifPerJam;

    public PegawaiFreelance(
            String nama,
            int jumlahJam,
            double tarifPerJam) {
        super(nama);
        this.jumlahJam = jumlahJam;
        this.tarifPerJam = tarifPerJam;
    }

    @Override
    public double hitungGaji() {
        return jumlahJam * tarifPerJam;
    }

    @Override
    public void tampilkanStatusKontrak() {
        System.out.println("Status: Pegawai Freelance");
    }
}
```

### E. File `Main.java`

java
```
public class Main {
    public static void main(String[] args) {
        Pegawai[] daftarPegawai = {
            new PegawaiTetap("Andi", 5000000),
            new PegawaiFreelance("Budi", 80, 50000)
        };

        for (Pegawai pegawai : daftarPegawai) {
            System.out.println("\nNama: " + pegawai.getNama());

            if (pegawai instanceof Kontrak) {
                ((Kontrak) pegawai).tampilkanStatusKontrak();
            }

            System.out.println(
                "Gaji: Rp" + pegawai.hitungGaji()
            );
        }
    }
}
```

### F. Output yang diharapkan

text
```
Nama: Andi
Status: Pegawai Tetap
Gaji: Rp5000000.0

Nama: Budi
Status: Pegawai Freelance
Gaji: Rp4000000.0
```

### G. Konsep OOP yang diterapkan

- Abstract class: `Pegawai` mendefinisikan atribut nama dan method abstrak `hitungGaji()`.
- Interface: `Kontrak` mewajibkan implementasi `tampilkanStatusKontrak()`.
- Inheritance: `PegawaiTetap` dan `PegawaiFreelance` mewarisi `Pegawai`.
- Polymorphism: array `Pegawai[]` menyimpan dua jenis objek dengan implementasi `hitungGaji()` yang berbeda.
- Method overriding: kedua class turunan menyediakan implementasi method yang sesuai dengan jenis pegawainya.
