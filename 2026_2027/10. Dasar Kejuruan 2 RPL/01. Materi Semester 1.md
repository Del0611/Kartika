## BAB 1: PENGENALAN DUNIA KERJA DAN K3 DI BIDANG IT

### 1.1 Apa Itu Kecakapan Kerja?

#### A. Pengertian
**Kecakapan kerja** adalah kemampuan yang harus dimiliki seseorang agar bisa bekerja dengan baik, produktif, dan profesional. Kecakapan kerja terbagi menjadi dua:

| Jenis | Penjelasan | Contoh |
|-------|------------|--------|
| **Hard Skills** | Kemampuan teknis yang spesifik | Coding, menginstal jaringan, desain grafis |
| **Soft Skills** | Kemampuan interpersonal dan karakter | Komunikasi, kerja tim, disiplin |

#### B. Mengapa Kecakapan Kerja Penting?
1. **Dunia kerja semakin kompetitif** - Perusahaan mencari orang yang tidak hanya pintar tapi juga profesional.
2. **Kemampuan beradaptasi** - Teknologi berubah cepat, kita harus bisa belajar hal baru.
3. **Bekerja dalam tim** - Hampir semua pekerjaan dilakukan dalam tim.
4. **Karir jangka panjang** - Soft skills membantu naik jabatan.

#### C. Contoh Kecakapan Kerja untuk Siswa SMK

| Kecakapan | Penjelasan | Contoh di Sekolah |
|-----------|------------|-------------------|
| **Disiplin** | Menaati aturan dan tepat waktu | Datang ke sekolah tepat waktu, mengumpulkan tugas tepat waktu |
| **Tanggung Jawab** | Bertanggung jawab atas tugas | Menyelesaikan proyek dengan baik, menjaga peralatan sekolah |
| **Kerja Sama** | Bekerja dengan orang lain | Kerja kelompok, gotong royong membersihkan lab |
| **Komunikasi** | Menyampaikan ide dengan jelas | Presentasi di depan kelas, diskusi kelompok |
| **Kreativitas** | Berpikir out of the box | Membuat karya orisinal, solusi unik untuk masalah |
| **Etos Kerja** | Rajin dan ulet | Belajar sungguh-sungguh, tidak mudah menyerah |

### 1.3 Keselamatan dan Kesehatan Kerja (K3) di Lingkungan IT

#### A. Apa Itu K3?
**K3** = Keselamatan dan Kesehatan Kerja. K3 bertujuan melindungi pekerja dari kecelakaan dan penyakit akibat kerja.

#### B. Bahaya di Lingkungan IT
| Jenis Bahaya | Contoh | Dampak |
|--------------|--------|--------|
| **Listrik** | Kabel terbuka, stop kontak overload | Tersengat listrik, kebakaran |
| **Ergonomi** | Posisi duduk salah, monitor terlalu rendah | Nyeri punggung, CVS (mata) |
| **Kebakaran** | Kabel short, perangkat overheat | Kerusakan alat, bahaya jiwa |
| **Kesehatan Mental** | Stres, burnout | Depresi, produktivitas turun |
| **Debu** | Debu di dalam CPU, keyboard | Kerusakan perangkat, alergi |

#### C. Cara Mencegah Kecelakaan di Lab Komputer
| Langkah | Penjelasan |
|---------|------------|
| 1. **Rapikan Kabel** | Gunakan cable ties, tidak berserakan di lantai |
| 2. **Gunakan Grounding** | Pastikan stop kontak memiliki grounding |
| 3. **Atur Posisi Monitor** | Setinggi mata, jarak 50-70 cm |
| 4. **Pakai Kursi Ergonomis** | Sandaran punggung, tinggi kursi sesuai |
| 5. **Istirahat Setiap 1 Jam** | Berdiri, peregangan, lihat jauh |
| 6. **Bersihkan Komputer** | Bersihkan debu secara rutin |
| 7. **Matikan Perangkat** | Matikan jika tidak digunakan |

#### D. 5 Aturan Safety di Lab Komputer
1. **Jangan makan/minum** di dekat komputer.
2. **Matikan komputer** jika selesai menggunakan.
3. **Laporkan kerusakan** ke guru/teknisi.
4. **Gunakan peralatan dengan benar**.
5. **Jaga kebersihan** lab komputer.

### 1.4 Ergonomi di Depan Komputer

#### A. Apa Itu Ergonomi?
**Ergonomi** adalah ilmu yang mempelajari cara bekerja yang nyaman dan aman agar tubuh tidak sakit.

#### B. Posisi Duduk yang Benar di Depan Komputer
```
+-----------------------------------------------+
|  ^                                            |
|  |  Mata sejajar dengan bagian atas monitor    |
|  |  Jarak mata ke monitor: 50-70 cm           |
|  |  Punggung tegak, bersandar ke kursi        |
|  |  Siku membentuk sudut 90°                  |
|  |  Kaki menapak ke lantai                    |
|  |  Pergelangan tangan lurus saat mengetik    |
+-----------------------------------------------+
```

#### C. Aturan 20-20-20
Setiap **20 menit**:
- Lihat ke arah sejauh **20 kaki** (sekitar 6 meter)
- Selama **20 detik**

#### D. Latihan Peregangan Sederhana
1. **Leher** - Miringkan kepala ke kanan dan kiri
2. **Bahu** - Angkat bahu ke atas, putar ke belakang
3. **Pergelangan Tangan** - Putar pergelangan searah jarum jam
4. **Punggung** - Duduk tegak, putar badan ke kanan dan kiri
5. **Mata** - Pejamkan mata 10 detik

#### E. Akibat Jika Ergonomi Buruk
| Masalah | Gejala |
|---------|--------|
| Computer Vision Syndrome | Mata lelah, kabur, sakit kepala |
| Carpal Tunnel Syndrome | Nyeri pergelangan tangan |
| Nyeri Punggung | Punggung bawah sakit, kaku |
| Text Neck | Leher dan bahu sakit |

### 1.6 Prosedur Kerja dan SOP Dasar

#### A. Apa Itu SOP?
**SOP** = Standar Operasional Prosedur, yaitu langkah-langkah baku untuk melakukan suatu pekerjaan.

#### B. Contoh SOP Sederhana: Menyalakan Komputer Lab
| Langkah | Aktivitas |
|---------|-----------|
| 1 | Pastikan kabel listrik terhubung |
| 2 | Tekan tombol power pada CPU |
| 3 | Tunggu hingga muncul layar login |
| 4 | Masukkan username dan password |
| 5 | Tunggu hingga desktop muncul |

#### C. Contoh SOP: Mematikan Komputer dengan Benar
| Langkah | Aktivitas |
|---------|-----------|
| 1 | Tutup semua aplikasi yang terbuka |
| 2 | Klik Start → Shutdown / Turn Off |
| 3 | Tunggu sampai komputer benar-benar mati |
| 4 | Matikan monitor dan stabilizer |

#### D. Contoh SOP: Menggunakan Laboratorium Komputer
1. **Datang tepat waktu** - 5 menit sebelum jam pelajaran.
2. **Duduk di kursi yang telah ditentukan**.
3. **Tidak makan dan minum** di dalam lab.
4. **Jaga kebersihan** - Buang sampah pada tempatnya.
5. **Tidak mengubah setting komputer** tanpa izin.
6. **Laporkan kerusakan** ke guru atau teknisi.
7. **Kembalikan kursi dan bersihkan meja** setelah selesai.

#### A. Jenis Tools Pengembangan
| Jenis Tools | Contoh | Fungsi |

#### B. Mengenal Visual Studio Code (VS Code)
**VS Code** adalah editor teks yang populer untuk programmer.

**Fitur VS Code**:
1. **Syntax Highlighting** - Warna berbeda untuk kode.
2. **Auto Completion** - Menyarankan kode saat mengetik.
3. **Debugging** - Mencari error.
4. **Extensions** - Bisa ditambah plugin.

**Cara Install VS Code**:
1. Buka google.com → cari "Visual Studio Code Download".
2. Pilih sesuai sistem operasi (Windows/Mac/Linux).
3. Buka file installer dan ikuti instruksi.

#### C. Mengenal Git dan GitHub
**Git** adalah software untuk menyimpan versi kode (version control).
**GitHub** adalah platform online untuk menyimpan repositori Git.

**Istilah Git Dasar**:
| Istilah | Penjelasan |
|---------|------------|
| Repository | Tempat penyimpanan kode |
| Commit | Menyimpan perubahan kode |
| Push | Mengirim kode ke server |
| Pull | Mengambil kode dari server |
| Branch | Cabang kode untuk fitur baru |

**Contoh Perintah Git**:
```bash
# Inisialisasi repository
git init

# Menambahkan file ke staging
git add .

# Commit dengan pesan
git commit -m "Menambahkan file pertama"

# Menghubungkan ke GitHub
git remote add origin https://github.com/username/repo.git

# Push ke GitHub
git push -u origin main

# Pull dari GitHub
git pull origin main
```

#### D. Mengenal XAMPP (Database)
**XAMPP** adalah software yang berisi:
- **Apache** = Web server
- **MySQL** = Database
- **PHP** = Bahasa pemrograman
- **phpMyAdmin** = GUI untuk MySQL

**Fungsi XAMPP**: Untuk membuat dan mengelola database di komputer lokal.

## BAB 2: DASAR-DASAR JARINGAN KOMPUTER

### 2.1 Apa Itu Jaringan Komputer?

#### A. Pengertian Jaringan Komputer
**Jaringan komputer** adalah kumpulan dari dua atau lebih komputer yang saling terhubung untuk berbagi data, sumber daya, dan informasi.

**Ilustrasi Sederhana**:
```
+--------+     +--------+     +--------+
| Komp 1 |-----| Komp 2 |-----| Komp 3 |
+--------+     +--------+     +--------+
      \
       +--------+
       | Printer |
       +--------+
```

#### B. Tujuan Jaringan Komputer
1. **Berbagi Data** - File bisa diakses dari komputer lain.
2. **Berbagi Perangkat** - Printer, scanner bisa dipakai bersama.
3. **Komunikasi** - Email, chat, video call.
4. **Akses Internet** - Bisa mengakses informasi di seluruh dunia.
5. **Keamanan** - Data bisa di-backup di server pusat.

#### C. Istilah Penting dalam Jaringan
| Istilah | Penjelasan |
|---------|------------|
| Node | Perangkat yang terhubung (komputer, printer, smartphone) |
| Server | Komputer yang menyediakan layanan |
| Client | Komputer yang meminta layanan dari server |
| Topologi | Bentuk/struktur jaringan |
| Protokol | Aturan komunikasi |
| Bandwidth | Kapasitas kecepatan jaringan |

---

### 2.2 Manfaat dan Tujuan Jaringan

#### A. Manfaat Jaringan di Kehidupan Sehari-hari
| Bidang | Contoh |
|--------|--------|
| **Pendidikan** | E-learning, akses jurnal, tugas online |
| **Perkantoran** | Email, sharing file, meeting online |
| **Perbankan** | ATM, mobile banking, transfer online |
| **Kesehatan** | Rekam medis elektronik, telemedicine |
| **Hiburan** | Streaming, game online, media sosial |
| **Transportasi** | Tiket online, GPS, ojek online |

#### B. Kelebihan Jaringan Komputer
1. **Efisiensi** - Sumber daya bisa dipakai bersama.
2. **Kecepatan** - Berbagi data dengan cepat.
3. **Keandalan** - Bisa ada backup.
4. **Biaya Lebih Murah** - Tidak perlu printer untuk setiap komputer.
5. **Komunikasi** - Terhubung dengan siapa saja.

#### C. Kekurangan Jaringan
1. **Kompleksitas** - Butuh keahlian untuk mengelola.
2. **Keamanan** - Ancaman hacking, virus.
3. **Ketergantungan** - Jika server down, semua terganggu.
4. **Biaya Awal** - Butuh perangkat tambahan.

---

### 2.3 Jenis-Jenis Jaringan (LAN, MAN, WAN, Internet)

#### A. LAN (Local Area Network)
**LAN** adalah jaringan yang mencakup area kecil seperti satu ruangan, satu gedung, atau satu sekolah.

**Karakteristik LAN**:
- Jarak: < 100 meter (kabel) / < 1 km (wireless)
- Kecepatan: 10 Mbps - 10 Gbps
- Contoh: Jaringan di lab komputer sekolah

```
+----------------------------------------+
|            JARINGAN LAN                 |
+----------------------------------------+
|                                         |
|  Lab Komputer 1      Lab Komputer 2     |
|  +--------+          +--------+         |
|  | Komp 1 |----------| Komp 5 |         |
|  | Komp 2 |          | Komp 6 |         |
|  | Komp 3 |          | Komp 7 |         |
|  | Komp 4 |          | Komp 8 |         |
|  +--------+          +--------+         |
|       |                    |            |
|       +---------+----------+            |
|                 |                       |
|            +---------+                  |
|            | Switch  |                  |
|            +---------+                  |
+----------------------------------------+
```

#### B. MAN (Metropolitan Area Network)
**MAN** adalah jaringan yang mencakup area kota (10-50 km).

**Karakteristik MAN**:
- Jarak: 10-50 km
- Kecepatan: 10-100 Mbps
- Contoh: Jaringan antar sekolah dalam satu kota

#### C. WAN (Wide Area Network)
**WAN** adalah jaringan yang mencakup area luas (antar kota, antar negara, bahkan benua).

**Karakteristik WAN**:
- Jarak: > 50 km
- Kecepatan: Bervariasi (1 Mbps - 10 Gbps)
- Contoh: Internet, jaringan antar kantor cabang

#### D. Internet

**Perbedaan LAN, MAN, WAN, Internet**:

### 2.5 Topologi Jaringan (Bus, Star, Ring, Mesh)

#### A. Topologi Bus
**Ciri**: Semua perangkat terhubung ke satu kabel utama (backbone).

```
+=====+    +=====+    +=====+    +=====+
| PC1 |----| PC2 |----| PC3 |----| PC4 |
+=====+    +=====+    +=====+    +=====+
          (Kabel Utama)
```

| Kelebihan | Kekurangan |
|-----------|------------|
| Hemat kabel | Jika kabel utama putus, semua mati |
| Mudah dipasang | Sulit mencari masalah (troubleshoot) |
| | Jika banyak perangkat, lambat |

**Kapan digunakan?** Jaringan kecil dengan 4-5 perangkat.

---

#### B. Topologi Star
**Ciri**: Semua perangkat terhubung ke perangkat pusat (switch/hub).

```
+=========+
|  SWITCH |---- PC1
|  / HUB  |---- PC2
|         |---- PC3
+=========+---- PC4
```

| Kelebihan | Kekurangan |
|-----------|------------|
| Jika satu komputer mati, yang lain tetap jalan | Bergantung pada switch/hub (jika rusak, semua mati) |
| Mudah menambah perangkat | Butuh kabel lebih banyak |
| Mudah troubleshoot | Biaya lebih mahal |

**Kapan digunakan?** Jaringan di kantor, sekolah, lab komputer. Ini adalah yang paling umum!

---

#### C. Topologi Ring
**Ciri**: Perangkat membentuk lingkaran.

```
+----+    +----+
| PC1|----| PC2|
+----+    +----+
  |         |
+----+    +----+
| PC4|----| PC3|
+----+    +----+
```

| Kelebihan | Kekurangan |
|-----------|------------|
| Tidak ada collision (benturan data) | Jika satu perangkat mati, semua mati |
| Performa stabil | Sulit menambah perangkat |

---

#### D. Topologi Mesh
**Ciri**: Setiap perangkat terhubung ke semua perangkat lain.

```
    +----+        +----+
    | PC1|--------| PC2|
    +----+        +----+
    / | \        / | \
   /  |  \      /  |  \
+----+ +----+  +----+ +----+
| PC3| | PC4|  | PC5| | PC6|
+----+ +----+  +----+ +----+
```

| Kelebihan | Kekurangan |
|-----------|------------|
| Sangat handal (redundansi tinggi) | Sangat mahal |
| Jika satu jalur putus, ada alternatif | Kompleks |

**Kapan digunakan?** Jaringan militer, bank, data center besar.

#### E. Perbandingan Topologi
| Topologi | Biaya | Keandalan | Kecepatan | Kompleksitas |
|----------|-------|-----------|-----------|--------------|
| Bus | Murah | Rendah | Sedang | Rendah |
| Star | Sedang | Tinggi | Tinggi | Sedang |
| Ring | Sedang | Sedang | Tinggi | Sedang |
| Mesh | Mahal | Sangat Tinggi | Sangat Tinggi | Tinggi |

### 2.6 Perangkat Jaringan (Switch, Router, Access Point, Hub)

#### A. Hub
**Hub** adalah perangkat sederhana yang meneruskan data ke semua port.

**Karakteristik**:
- Bekerja di layer 1 (Physical)
- Tidak pintar - semua data disiarkan ke semua perangkat
- Kecepatan: 10/100 Mbps
- Saat ini sudah jarang digunakan (digantikan switch)

#### B. Switch
**Switch** adalah perangkat yang lebih pintar dari hub.

**Karakteristik**:
- Bekerja di layer 2 (Data Link)
- Mengenal MAC address
- Mengirim data hanya ke perangkat tujuan
- Kecepatan: 10/100/1000 Mbps (Gigabit)

**Fungsi Switch**:
1. Menghubungkan banyak perangkat dalam satu jaringan.
2. Meneruskan data ke perangkat yang tepat.
3. Membantu mengurangi collision (benturan data).

#### C. Router
**Router** adalah perangkat untuk menghubungkan jaringan yang berbeda.

**Karakteristik**:
- Bekerja di layer 3 (Network)
- Mengenal IP address
- Bisa menghubungkan LAN ke internet

**Fungsi Router**:
1. Menghubungkan LAN ke WAN/Internet.
2. Melakukan routing (menentukan jalur terbaik).
3. Melakukan NAT (Network Address Translation).
4. Firewall dasar.

#### D. Access Point (AP)
**Access Point** adalah perangkat untuk menyediakan koneksi wireless (WiFi).

**Karakteristik**:
- Mengubah sinyal kabel menjadi sinyal wireless
- Terhubung ke switch/router

**Fungsi Access Point**:
1. Memberikan akses WiFi ke smartphone, laptop, tablet.
2. Memperluas jangkauan jaringan.

#### E. Perbandingan Perangkat Jaringan
| Perangkat | Layer | Fungsi Utama | Kecerdasan |
|-----------|-------|--------------|------------|
| Hub | 1 | Broadcast data | Rendah |
| Switch | 2 | Forward berdasarkan MAC | Sedang |
| Router | 3 | Routing antar network | Tinggi |
| Access Point | 2 | Koneksi wireless | Sedang |

### 2.7 Pengenalan IP Address dan Subnetting Dasar

#### A. Apa Itu IP Address?
**IP Address** adalah alamat unik yang diberikan ke setiap perangkat di jaringan (seperti alamat rumah).

**Contoh IP Address**: `192.168.1.1`

**Format IP Address**:
- 4 angka yang dipisahkan titik (.)
- Setiap angka antara 0-255
- Contoh: `192.168.1.10`, `10.0.0.1`, `172.16.0.5`

#### B. Jenis IP Address
| Jenis | Rentang | Penggunaan |
|-------|---------|------------|
| IP Public | Bervariasi | Digunakan di internet (unik di seluruh dunia) |
| IP Private | 10.0.0.0 - 10.255.255.255 | Digunakan di dalam jaringan lokal |
| IP Private | 172.16.0.0 - 172.31.255.255 | Digunakan di dalam jaringan lokal |
| IP Private | 192.168.0.0 - 192.168.255.255 | Digunakan di dalam jaringan lokal |

#### C. IP Public vs IP Private
**IP Public**:
- Bisa diakses dari mana saja di internet.
- Diberikan oleh ISP (Internet Service Provider).
- Contoh: 8.8.8.8 (Google DNS)

**IP Private**:
- Hanya bisa diakses di dalam jaringan lokal.
- Tidak bisa diakses langsung dari internet.
- Contoh: 192.168.1.10 (Komputer di rumah)

#### D. Subnet Mask
**Subnet Mask** adalah angka yang menunjukkan bagian mana dari IP yang merupakan alamat jaringan dan bagian mana yang alamat perangkat.

**Contoh Subnet Mask**:
| Subnet Mask | Jumlah Host | Digunakan untuk |
|-------------|-------------|-----------------|
| 255.255.255.0 (/24) | 254 host | Jaringan kecil (rumah, kantor kecil) |
| 255.255.0.0 (/16) | 65.534 host | Jaringan menengah (kampus) |
| 255.0.0.0 (/8) | 16.777.214 host | Jaringan besar (ISP) |

#### E. Cara Mengecek IP Address di Windows
1. Buka **Command Prompt** (CMD).
2. Ketik `ipconfig` dan tekan Enter.
3. Cari bagian "IPv4 Address".

**Contoh Output**:
```
IPv4 Address. . . . . . . . . . . : 192.168.1.10
Subnet Mask . . . . . . . . . . . : 255.255.255.0
Default Gateway . . . . . . . . . : 192.168.1.1
```

#### F. Cara Mengecek IP Address di Linux
1. Buka terminal.
2. Ketik `ifconfig` atau `ip addr`.

### 2.8 Mengenal Kabel Jaringan (UTP, STP, Fiber Optic)

#### A. Kabel UTP (Unshielded Twisted Pair)
**UTP** adalah kabel yang paling umum digunakan untuk jaringan LAN.

**Karakteristik**:
- Ada 8 kabel kecil yang dipilin berpasangan
- Menggunakan konektor RJ45
- Kecepatan: 10 Mbps - 10 Gbps
- Jarak maksimal: 100 meter

**Kategori Kabel UTP**:
| Kategori | Kecepatan | Penggunaan |
|----------|-----------|------------|
| Cat5 | 100 Mbps | Jaringan lama |
| Cat5e | 1 Gbps | Rumah, kantor kecil |
| Cat6 | 10 Gbps (max 55m) | Kantor, gaming |
| Cat6a | 10 Gbps (max 100m) | Enterprise |

#### B. Kabel STP (Shielded Twisted Pair)
**STP** adalah kabel UTP dengan pelindung (shield) untuk mengurangi interferensi.

**Karakteristik**:
- Lebih tahan gangguan
- Lebih mahal dari UTP
- Digunakan di area dengan banyak gangguan

#### C. Kabel Fiber Optic
**Fiber Optic** adalah kabel yang menggunakan cahaya untuk mengirim data.

**Karakteristik**:
- Sangat cepat (hingga 100 Gbps)
- Jarak jauh (hingga 100 km)
- Tidak ada interferensi
- Lebih mahal

**Jenis Fiber Optic**:
| Jenis | Jarak | Penggunaan |
|-------|-------|------------|
| Singlemode | 100 km+ | Antar kota, backbone internet |
| Multimode | 300m - 2km | Dalam gedung, data center |

#### D. Perbandingan Kabel Jaringan
| Aspek | UTP | STP | Fiber Optic |
|-------|-----|-----|-------------|
| Kecepatan | Sedang-Cepat | Sedang-Cepat | Sangat Cepat |
| Jarak | 100m | 100m | 100 km+ |
| Biaya | Murah | Sedang | Mahal |
| Gangguan | Mudah kena gangguan | Tahan gangguan | Tidak ada gangguan |
| Penggunaan | Rumah, kantor | Area dengan interferensi | Backbone, data center |

#### E. Urutan Kabel UTP (Standar T568B)
```
Urutan Kabel dari kiri ke kanan (jika melihat ke arah pin konektor):

1. Putih-Oranye
2. Oranye
3. Putih-Hijau
4. Biru
5. Putih-Biru
6. Hijau
7. Putih-Coklat
8. Coklat

+-----+
| 1 2 |  <- Putih-Oranye, Oranye
| 3 4 |  <- Putih-Hijau, Biru
| 5 6 |  <- Putih-Biru, Hijau
| 7 8 |  <- Putih-Coklat, Coklat
+-----+
```

### 2.9 Praktik: Crimping Kabel UTP dan Konfigurasi Dasar

#### A. Alat dan Bahan

#### B. Langkah-Langkah Crimping (Straight Cable)
**Straight Cable** - Digunakan untuk menghubungkan perangkat yang berbeda (PC ke Switch, PC ke Router).

| Langkah | Aktivitas | Gambar |
|---------|-----------|--------|
| 1 | Kupas kulit luar kabel UTP 2-3 cm | |
| 2 | Rapikan 8 kabel kecil sesuai urutan T568B | |
| 3 | Potong kabel agar rata (sejajar) | |
| 4 | Masukkan kabel ke konektor RJ45 | |
| 5 | Pastikan kabel menyentuh ujung konektor | |

| 7 | Lakukan hal yang sama di ujung lain | |
| 8 | Tes dengan cable tester | |

**Urutan T568B di kedua ujung (straight):**
```
Ujung 1: WO - O - WH - B - WB - H - WC - C
Ujung 2: WO - O - WH - B - WB - H - WC - C
```

**Urutan T568B di ujung 1 dan T568A di ujung 2 (crossover):**
```
Ujung 1 (T568B): WO - O - WH - B - WB - H - WC - C
Ujung 2 (T568A): WH - H - WO - B - WB - O - WC - C
```

#### C. Praktik: Menghubungkan Komputer ke Switch
1. Siapkan kabel UTP straight yang sudah dicrimping.
2. Masukkan satu ujung ke port komputer.
3. Masukkan ujung lain ke port switch.
4. Pastikan LED di switch dan komputer menyala.

#### D. Praktik: Menghubungkan Dua Komputer (Tanpa Switch)
1. Siapkan kabel crossover (T568B - T568A).
2. Masukkan ke masing-masing komputer.
3. Setting IP manual:
   - Komputer 1: 192.168.1.1
   - Komputer 2: 192.168.1.2
   - Subnet Mask: 255.255.255.0
4. Test dengan `ping 192.168.1.2` dari komputer 1.

#### E. Praktik: Konfigurasi IP Static di Windows
1. Buka **Control Panel** → **Network and Sharing Center**.
2. Klik **Change adapter settings**.
3. Klik kanan **Ethernet** → **Properties**.
4. Pilih **Internet Protocol Version 4 (TCP/IPv4)** → Klik **Properties**.
5. Pilih **Use the following IP address**.
6. Isi:
   - IP Address: 192.168.1.10
   - Subnet Mask: 255.255.255.0
   - Default Gateway: 192.168.1.1
7. Klik **OK** → **OK**.

#### F. Praktik: Test Jaringan dengan Ping
**Perintah Ping**:
```cmd
ping [alamat IP]
ping 8.8.8.8
ping google.com
```

**Hasil Ping**:
- **Reply from**: Jaringan berhasil
- **Request timed out**: Ada masalah koneksi
- **Destination host unreachable**: Perangkat tidak ditemukan

### 3.2 Flowchart dan Pseudocode

#### A. Apa Itu Flowchart?
**Flowchart** adalah diagram yang menunjukkan langkah-langkah algoritma menggunakan simbol-simbol tertentu.

**Simbol Flowchart**:
| Simbol | Nama | Fungsi |
|--------|------|--------|
| ⟷ | Terminal (Start/End) | Awal dan akhir program |
| ▭ | Process | Operasi/kalkulasi |
| ◇ | Decision | Percabangan (if-else) |
| ▱ | Input/Output | Masukan/keluaran data |
| → | Arrow | Arah aliran program |
| ○ | Connector | Menghubungkan halaman |

#### B. Contoh Flowchart Sederhana (Menentukan Bilangan Ganjil/Genap)
```
    +--------+
    | START  |
    +---+----+
        |
        v
    +---+----+
    | INPUT n|
    +---+----+
        |
        v
    +---+----+  Yes
    | n % 2  |-----> +----------------+
    | == 0   |      | PRINT "Genap"  |
    +---+----+      +-------+--------+
        | No               |
        v                   |
    +---+----+              |
    | PRINT  |              |
    | "Ganjil"|             |
    +---+----+              |
        |                   |
        v                   |
    +---+----+              |
    |  END   |<-------------+
    +--------+
```

#### C. Pseudocode
**Pseudocode** adalah cara menulis algoritma dengan bahasa campuran (mirip bahasa sehari-hari + kode).

**Contoh Pseudocode (Bilangan Ganjil/Genap)**:
```
START
    INPUT n
    IF n % 2 == 0 THEN
        PRINT "Genap"
    ELSE
        PRINT "Ganjil"
    ENDIF
END
```

**Contoh Pseudocode (Mencari Nilai Maksimum)**:
```
START

    IF a > b AND a > c THEN
        max = a
    ELSE IF b > a AND b > c THEN
        max = b
    ELSE
        max = c
    ENDIF
    PRINT max
END
```

## BAB 4: PENGENALAN PEMROGRAMAN BERORIENTASI OBJEK (OOP)

### 4.1 Apa Itu OOP?

#### A. Pengertian OOP
**OOP (Object-Oriented Programming)** adalah cara pemrograman yang menggunakan "objek" untuk menyimpan data dan perilaku.

**Bayangkan Dunia Nyata**:
- **Mobil** adalah objek → punya warna, merk, kecepatan (atribut) dan bisa jalan, berhenti, klakson (metode).
- **Siswa** adalah objek → punya nama, kelas, NIS (atribut) dan bisa belajar, ujian (metode).

#### B. Konsep Dasar OOP
| Konsep | Penjelasan | Contoh |
|--------|------------|--------|
| **Kelas** | Cetak biru untuk membuat objek | Blueprint mobil |
| **Objek** | Hasil cetakan dari kelas | Mobil Toyota, Mobil Honda |
| **Atribut** | Data/karakteristik | Warna, merk, kecepatan |
| **Metode** | Perilaku/fungsi | jalan(), berhenti(), klakson() |

#### C. Mengapa Belajar OOP?
1. **Memodelkan dunia nyata** - Lebih mudah memahami.
2. **Kode lebih rapi** - Terstruktur dalam kelas.
3. **Bisa dipakai ulang** - Reusable code.
4. **Banyak digunakan** - Java, C++, Python, C# (Unity).

---

### 4.2 Perbedaan Prosedural vs OOP

#### A. Pemrograman Prosedural
**Ciri**:
- Fokus pada fungsi/prosedur.
- Data dan fungsi terpisah.
- Contoh: C, Pascal, BASIC.

**Contoh Prosedural (Mobil)**:
```python
# Prosedural - data dan fungsi terpisah
mobil_warna = "Merah"
mobil_merk = "Toyota"
mobil_kecepatan = 0

def gas(kecepatan):
    global mobil_kecepatan
    mobil_kecepatan += kecepatan

def rem(kecepatan):
    global mobil_kecepatan
    mobil_kecepatan -= kecepatan
```

#### B. Pemrograman OOP
**Ciri**:
- Fokus pada objek (data + fungsi).
- Data dan fungsi dibungkus dalam kelas.
- Contoh: Java, C++, Python (dengan class), C#.

**Contoh OOP (Mobil)**:
```python
# OOP - data dan fungsi dalam kelas
class Mobil:
    def __init__(self, warna, merk):
        self.warna = warna
        self.merk = merk
        self.kecepatan = 0

    def gas(self, kecepatan):
        self.kecepatan += kecepatan

    def rem(self, kecepatan):
        self.kecepatan -= kecepatan
```

#### C. Perbandingan
| Aspek | Prosedural | OOP |
|-------|------------|-----|
| Fokus | Fungsi | Objek |
| Data | Terpisah dari fungsi | Dibungkus dalam objek |
| Keamanan | Data bisa diubah siapa saja | Data bisa dilindungi |
| Kompleksitas | Sulit untuk besar | Lebih terkelola |
| Reusability | Copy-paste code | Inheritance |

---

### 4.3 Kelas dan Objek

#### A. Membuat Kelas di Python
```python
class Mobil:
    # Atribut kelas (milik semua objek)
    jumlah_roda = 4

    # Constructor (dijalankan saat objek dibuat)
    def __init__(self, merk, warna):
        self.merk = merk      # Atribut instance
        self.warna = warna    # Atribut instance

    # Metode (perilaku)
    def info(self):
        return f"Mobil {self.merk} berwarna {self.warna}"
```

#### B. Membuat Objek (Instance)
```python
# Membuat objek dari kelas Mobil

mobil2 = Mobil("Honda", "Biru")

# Mengakses atribut
print(mobil1.merk)    # Toyota
print(mobil2.warna)   # Biru

# Memanggil metode
print(mobil1.info())  # Mobil Toyota berwarna Merah
print(mobil2.info())  # Mobil Honda berwarna Biru
```

#### C. Contoh: Kelas Siswa
```python
class Siswa:
    def __init__(self, nama, kelas, nis):
        self.nama = nama
        self.kelas = kelas
        self.nis = nis
        self.nilai = []

    def tambah_nilai(self, nilai):
        self.nilai.append(nilai)

    def rata_rata(self):
        if len(self.nilai) == 0:
            return 0
        return sum(self.nilai) / len(self.nilai)

    def info(self):
        return f"Siswa: {self.nama} (NIS: {self.nis}), Kelas: {self.kelas}"

# Membuat objek
budi = Siswa("Budi", "XII RPL 1", "12345")
budi.tambah_nilai(85)
budi.tambah_nilai(90)
budi.tambah_nilai(78)

print(budi.info())                    # Siswa: Budi (NIS: 12345), Kelas: XII RPL 1
print(f"Rata-rata: {budi.rata_rata()}")  # Rata-rata: 84.33
```

### 4.4 Atribut dan Metode

#### A. Atribut Instance vs Atribut Kelas
| Jenis | Dimiliki | Contoh |
|-------|----------|--------|
| Atribut Instance | Setiap objek | `self.nama`, `self.warna` |
| Atribut Kelas | Semua objek | `jumlah_roda = 4` |

```python

    jenis = "Mamalia"
    jumlah_kucing = 0

    def __init__(self, nama):
        # Atribut instance (unik per objek)
        self.nama = nama
        Kucing.jumlah_kucing += 1
```

#### B. Metode Instance vs Metode Kelas
```python
class Matematika:
    # Metode instance (bisa akses self)
    def tambah(self, a, b):
        return a + b

    # Metode kelas (@classmethod)
    @classmethod
    def info(cls):
        return "Ini adalah kelas Matematika"

    # Metode statis (@staticmethod) - tidak butuh self/cls
    @staticmethod
    def pi():
        return 3.14

# Penggunaan
mtk = Matematika()
print(mtk.tambah(5, 3))     # 8 (instance method)
print(Matematika.info())    # Ini adalah kelas Matematika (class method)
print(Matematika.pi())      # 3.14 (static method)
```

### 4.6 Enkapsulasi Dasar (Public, Private)

#### A. Apa Itu Enkapsulasi?
**Enkapsulasi** adalah prinsip untuk menyembunyikan data dan hanya bisa diakses melalui metode tertentu.

**Tujuan Enkapsulasi**:
1. Melindungi data dari perubahan yang tidak diinginkan.
2. Memudahkan pemeliharaan kode.
3. Keamanan data.

#### B. Access Modifiers di Python
| Modifier | Penulisan | Akses |
|----------|-----------|-------|
| Public | `nama` | Bisa diakses dari mana saja |
| Protected | `_nama` | Hanya dalam kelas dan turunannya |
| Private | `__nama` | Hanya dalam kelas itu sendiri |

**Contoh**:
```python
class BankAccount:
    def __init__(self, pemilik, saldo):
        self.pemilik = pemilik          # public
        self._saldo = saldo             # protected
        self.__pin = "1234"             # private

    def get_saldo(self):
        return self._saldo

    def set_saldo(self, jumlah):
        if jumlah >= 0:
            self._saldo = jumlah
        else:
            print("Saldo tidak boleh negatif!")

    def get_pin(self):
        return "****"  # Tidak ditampilkan

akun = BankAccount("Budi", 1000)
print(akun.pemilik)        # Budi (public - bisa diakses)
print(akun._saldo)         # 1000 (protected - bisa diakses, tapi sebaiknya tidak)
print(akun.get_saldo())    # 1000 (pakai method)

# print(akun.__pin)        # ERROR! Private tidak bisa diakses
print(akun.get_pin())      # **** (pakai method)
```

### 4.7 Pewarisan (Inheritance) Dasar

#### A. Apa Itu Pewarisan?
**Pewarisan (Inheritance)** adalah kemampuan sebuah kelas untuk mewarisi atribut dan metode dari kelas lain.

**Manfaat Pewarisan**:
1. **Reusability** - Kode dapat digunakan ulang.
2. **Hierarki** - Membuat struktur yang terorganisir.
3. **Ekstensibilitas** - Menambah fitur tanpa mengubah parent.

#### B. Contoh Pewarisan Sederhana
```python
# Kelas Induk (Parent)
class Hewan:
    def __init__(self, nama, umur):
        self.nama = nama
        self.umur = umur

    def suara(self):
        return "Hewan mengeluarkan suara"

    def info(self):
        return f"Nama: {self.nama}, Umur: {self.umur} tahun"

# Kelas Anak (Child) - mewarisi Hewan
class Kucing(Hewan):
    def suara(self):  # Override (ganti perilaku)
        return "Meong!"

    def mengeong(self):  # Metode baru
        return "Miaw miaw!"

class Anjing(Hewan):
    def suara(self):  # Override
        return "Guk! Guk!"

# Penggunaan
kucing = Kucing("Tom", 3)
anjing = Anjing("Spike", 5)

print(kucing.info())     # Nama: Tom, Umur: 3 tahun (dari parent)
print(kucing.suara())    # Meong! (dari child - override)
print(kucing.mengeong()) # Miaw miaw! (metode child sendiri)
print(anjing.suara())    # Guk! Guk!
```

#### C. Pewarisan dengan Super()
**super()** digunakan untuk memanggil method dari kelas induk.

```python
class Siswa:

        return super().info() + f", Jurusan: {self.jurusan}"
```


#### B. Kasus: Sistem Manajemen Game Sederhana (Hero vs Monster)
```python
class Character:
    def __init__(self, name, hp, attack):
        self.name = name
        self.hp = hp
        self.max_hp = hp
        self.attack = attack
        self.is_alive = True

    def take_damage(self, damage):
        self.hp -= damage
        if self.hp <= 0:
            self.hp = 0
            self.is_alive = False
            print(f"{self.name} telah mati!")
        else:
            print(f"{self.name} menerima {damage} damage, HP tersisa: {self.hp}")

    def attack_target(self, target):
        if not self.is_alive:
            print(f"{self.name} sudah mati, tidak bisa menyerang!")
            return
        print(f"{self.name} menyerang {target.name}!")
        target.take_damage(self.attack)

    def info(self):
        return f"{self.name} - HP: {self.hp}/{self.max_hp}, Attack: {self.attack}"

class Hero(Character):
    def __init__(self, name):
        super().__init__(name, 100, 20)
        self.level = 1
        self.exp = 0

    def gain_exp(self, exp):
        self.exp += exp
        if self.exp >= 50:
            self.level_up()

    def level_up(self):
        self.level += 1
        self.exp = 0
        self.max_hp += 20
        self.hp = self.max_hp
        self.attack += 5
        print(f"{self.name} naik level! Level sekarang: {self.level}")

class Monster(Character):
    def __init__(self, name, hp, attack, exp_reward):
        super().__init__(name, hp, attack)
        self.exp_reward = exp_reward

# Main Game
def battle():
    hero = Hero("Hero")
    monsters = [
        Monster("Slime", 30, 5, 10),
        Monster("Goblin", 50, 8, 20),
        Monster("Skeleton", 70, 12, 30),
        Monster("Dragon", 150, 25, 50)
    ]

    print("=== SELAMAT DATANG DI ARENA PERTEMPURAN ===")
    print(hero.info())

    for monster in monsters:
        print(f"\n=== {monster.name} muncul! ===")
        while hero.is_alive and monster.is_alive:
            print("\n1. Serang")
            print("2. Info Hero")
            print("3. Lari")
            pilihan = input("Pilih aksi: ")

            if pilihan == "1":
                hero.attack_target(monster)
                if monster.is_alive:
                    monster.attack_target(hero)
            elif pilihan == "2":
                print(hero.info())
            elif pilihan == "3":
                print("Kamu melarikan diri!")
                return

        if hero.is_alive and not monster.is_alive:
            print(f"{monster.name} kalah!")
            hero.gain_exp(monster.exp_reward)
            print(hero.info())

        if not hero.is_alive:
            print("Game Over!")
            return

    print("\n=== SELAMAT! KAMU MENANG! ===")

if __name__ == "__main__":
    battle()
```

### 5.5 Analisis Algoritma Sederhana

#### A. Mengapa Menganalisis Algoritma?
Analisis algoritma membantu kita memilih algoritma yang paling efisien.

**Parameter Analisis**:
1. **Waktu** - Seberapa cepat algoritma berjalan.
2. **Memori** - Seberapa banyak memori yang digunakan.

#### B. Kompleksitas Waktu Sederhana
| Kompleksitas | Nama | Contoh | Keterangan |
|--------------|------|--------|------------|
| O(1) | Konstan | Akses array `arr[0]` | Waktu tetap, cepat |
| O(n) | Linear | Loop sekali `for i in range(n)` | Waktu proporsional dengan n |
| O(n²) | Kuadratik | Nested loop `for i in range(n): for j in range(n)` | Lambat untuk n besar |

#### C. Contoh Analisis Sederhana
**Contoh 1: Mencari Nilai Maksimum**
```python
def cari_maksimum(data):
    maks = data[0]           # O(1)
    for n in data:           # O(n) - iterasi sebanyak n
        if n > maks:
            maks = n         # O(1)
    return maks              # O(1)
# Total: O(n)
```

**Contoh 2: Bubble Sort**
```python
def bubble_sort(data):
    n = len(data)            # O(1)
    for i in range(n):       # O(n) - outer loop
        for j in range(n-i-1): # O(n) - inner loop
            if data[j] > data[j+1]:
                data[j], data[j+1] = data[j+1], data[j]
    return data
# Total: O(n²)
```

**Contoh 3: Pencarian Biner (Binary Search)**
```python
def binary_search(data, target):
    low = 0
    high = len(data) - 1
    while low <= high:       # O(log n) - data dibelah dua setiap iterasi
        mid = (low + high) // 2
        if data[mid] == target:
            return mid
        elif data[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
# Total: O(log n) - sangat cepat untuk data besar!
```

#### D. Perbandingan Kecepatan
| n | O(1) | O(log n) | O(n) | O(n²) |
|---|------|----------|------|-------|
| 10 | 1 | 3 | 10 | 100 |
| 100 | 1 | 7 | 100 | 10.000 |
| 1.000 | 1 | 10 | 1.000 | 1.000.000 |
| 10.000 | 1 | 13 | 10.000 | 100.000.000 |
