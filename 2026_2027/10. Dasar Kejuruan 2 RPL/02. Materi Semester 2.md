## BAB 6: KECAKAPAN KERJA DAN BUDAYA KERJA LANJUTAN

### 6.1 Manajemen Waktu dan Produktivitas

#### A. Mengapa Manajemen Waktu Penting?
Manajemen waktu adalah keterampilan mengatur waktu agar pekerjaan selesai tepat waktu dan efektif. Di dunia kerja, waktu adalah uang. Jika kita bisa mengelola waktu dengan baik, kita akan lebih produktif dan sukses.

**Akibat Manajemen Waktu Buruk**:
- Tugas menumpuk (deadline tidak terpenuhi)
- Stres dan kelelahan
- Kualitas kerja menurun
- Reputasi buruk di mata atasan/rekan

#### B. Metode Manajemen Waktu

**1. Metode Pomodoro**
Metode ini menggunakan timer untuk membagi waktu kerja menjadi interval 25 menit (1 pomodoro) dan istirahat 5 menit.

```
+-----------------------------------------------------+
|  Siklus Pomodoro                                    |
|                                                     |
|  [25 menit kerja] → [5 menit istirahat] → [ulangi]  |
|                                                     |
|  Setelah 4 siklus → istirahat panjang (15-30 menit) |
+-----------------------------------------------------+
```

**Cara Menerapkan**:
1. Tentukan tugas yang akan dikerjakan.
2. Set timer 25 menit.
3. Fokus bekerja tanpa gangguan.
4. Saat timer berbunyi, istirahat 5 menit.
5. Ulangi 4 kali, lalu istirahat panjang.

**2. Metode Eisenhower Matrix**
Memprioritaskan tugas berdasarkan urgensi dan kepentingan.

```
+--------------------------------+--------------------------------+
|         URGENT                 |         NOT URGENT             |
+--------------------------------+--------------------------------+
|  QUADRANT 1                    |  QUADRANT 2                    |
|  DO FIRST                      |  SCHEDULE                      |
|  - Deadline mendekat           |  - Perencanaan                 |
|  - Masalah kritis              |  - Belajar keterampilan baru   |
|  - Tugas penting mendesak      |  - Persiapan proyek            |
+--------------------------------+--------------------------------+
|  QUADRANT 3                    |  QUADRANT 4                    |
|  DELEGATE                      |  ELIMINATE                     |
|  - Telepon tidak penting       |  - Media sosial berlebihan     |
|  - Email yang tidak perlu      |  - Menonton TV tanpa tujuan    |
|  - Rapat yang tidak mendesak   |  - Gosip                       |
+--------------------------------+--------------------------------+
```

**3. Teknik To-Do List**
Buat daftar tugas harian:

```python
# Contoh To-Do List
TO-DO LIST - SENIN, 15 JANUARI 2024
======================================
[ ] Selesaikan tugas pemrograman (prioritas 1)
[ ] Belajar routing di Cisco (prioritas 2)
[ ] Review materi UAS (prioritas 3)
[ ] Bersihkan lab komputer (prioritas 4)
======================================
Selesai: ___ / 4
```

**Tips To-Do List**:
1. Tulis semua tugas yang harus dikerjakan.
2. Prioritaskan (tugas terpenting di atas).
3. Coret setelah selesai (rasa puas!).
4. Jangan terlalu banyak (maksimal 5-7 tugas/hari).

#### C. Mengatasi Prokrastinasi (Menunda-nunda)
**Prokrastinasi** adalah kebiasaan menunda pekerjaan penting.

**Penyebab Prokrastinasi**:
1. Tugas terasa sulit atau membosankan.
2. Perfeksionisme (takut hasil tidak sempurna).
3. Tidak jelas apa yang harus dikerjakan.
4. Distraksi (HP, sosial media, game).

**Cara Mengatasi**:
1. **Pecah tugas besar** menjadi tugas kecil.
2. **Gunakan teknik Pomodoro**.
3. **Hilangkan distraksi** - matikan notifikasi HP.
4. **Mulai dulu** - seringkali yang sulit adalah memulai.
5. **Beri reward** setelah menyelesaikan tugas.

### 6.2 Komunikasi Efektif di Tempat Kerja

#### A. Pentingnya Komunikasi
Komunikasi yang baik adalah kunci sukses di tempat kerja. Tanpa komunikasi yang efektif, terjadi kesalahpahaman, konflik, dan pekerjaan tidak selesai dengan baik.

**Jenis Komunikasi**:
| Jenis | Contoh | Kelebihan | Kekurangan |
|-------|--------|-----------|------------|
| Verbal (Lisan) | Presentasi, meeting, telepon | Langsung, personal | Tidak ada rekaman |
| Non-verbal | Bahasa tubuh, ekspresi | Menambah makna | Bisa salah tafsir |
| Tertulis | Email, laporan, chat | Ada rekaman, bisa dibaca ulang | Tidak ada intonasi |

#### B. 7C Komunikasi Efektif
| Prinsip | Penjelasan | Contoh Buruk | Contoh Baik |
|---------|------------|--------------|-------------|
| Clear (Jelas) | Mudah dipahami | "Tolong kerjakan itu" | "Tolong selesaikan laporan penjualan hari ini" |
| Concise (Ringkas) | Tidak bertele-tele | Email panjang 5 paragraf | Email 3 kalimat langsung ke inti |
| Concrete (Konkret) | Spesifik, ada contoh | "Perbaiki kode" | "Perbaiki bug di fungsi login (baris 45)" |
| Correct (Benar) | Informasi akurat | "Server error" tanpa detail | "Server error 500 di production" |
| Coherent (Koheren) | Logis dan terstruktur | Lompat-lompat tidak jelas | Urut dari awal sampai akhir |
| Complete (Lengkap) | Semua info tersampaikan | Tidak ada deadline | Deadline: Jumat jam 17:00 |
| Courteous (Santun) | Sopan dan ramah | "Kamu salah!" | "Mohon periksa kembali bagian ini" |

#### C. Komunikasi Tertulis: Email Profesional
**Struktur Email**:
```
1. SUBJECT: Singkat dan jelas (contoh: "Rapat Proyek - Senin 10:00")
2. SALAM: "Kepada Yth. Bapak/Ibu [Nama]"
3. ISI EMAIL:
   - Pembukaan (maksud email)
   - Isi (informasi yang disampaikan)
   - Penutup (harapan/tindakan selanjutnya)
4. TANDA TANGAN:
   Nama
   Jabatan/Posisi
   Kontak (HP, email)
```

**Contoh Email Profesional**:
```

Mohon bantuannya untuk melakukan review kode.

- Login dengan email dan password
- Reset password
- Validasi input

Link Pull Request: https://github.com/project-a/pull/45

Terima kasih atas waktunya.

Salam,
Budi Santoso
Developer
HP: 0812-3456-7890
```

#### D. Komunikasi Lisan: Presentasi
**Struktur Presentasi**:
1. **Pembukaan** (2-3 menit):
   - Perkenalan
   - Tujuan presentasi
   - Agenda

2. **Isi** (10-15 menit):
   - Poin-poin utama
   - Gunakan visual (diagram, screenshot)
   - Demo (jika ada)

3. **Penutup** (2-3 menit):
   - Ringkasan
   - Q&A
   - Terima kasih

**Tips Presentasi**:
1. Latih sebelum presentasi (3-4 kali).
2. Gunakan bahasa yang mudah dipahami.
3. Jangan membaca slide (gunakan bullet point).
4. Kontak mata dengan audiens.
5. Siapkan demo cadangan.

### 6.3 Bekerja dalam Tim (Teamwork)

#### A. Mengapa Teamwork Penting?
Di dunia kerja, hampir semua pekerjaan dilakukan dalam tim. Kemampuan bekerja sama dengan orang lain sangat penting untuk kesuksesan.

**Manfaat Bekerja dalam Tim**:
1. **Berbagi beban** - Tugas berat bisa dibagi.
2. **Ide lebih banyak** - Berbagai perspektif.
3. **Belajar dari orang lain** - Transfer pengetahuan.
4. **Motivasi** - Saling mendukung.
5. **Lebih cepat** - Pekerjaan selesai lebih cepat.

#### B. Peran dalam Tim
| Peran | Tanggung Jawab | Contoh |
|-------|---------------|--------|
| Pemimpin Tim | Mengarahkan, mengambil keputusan | Ketua proyek |
| Pelaksana | Melaksanakan tugas | Programmer, desainer |
| Komunikator | Menghubungkan tim dengan stakeholder | Project manager |
| Ahli | Memberikan keahlian spesifik | Database expert |
| Penguji | Memastikan kualitas | QA Tester |

#### C. Karakteristik Tim yang Baik
1. **Tujuan yang jelas** - Semua tahu apa yang ingin dicapai.
2. **Komunikasi terbuka** - Anggota tim saling bicara.
3. **Saling percaya** - Tidak ada saling curiga.
4. **Komitmen** - Semua berdedikasi pada tujuan.
5. **Akuntabilitas** - Bertanggung jawab atas tugas masing-masing.
6. **Konflik sehat** - Konflik diselesaikan dengan baik.

#### D. Cara Menjadi Anggota Tim yang Baik
1. **Komunikasikan ide dengan jelas**.
2. **Dengarkan pendapat orang lain**.
3. **Bantu rekan yang kesulitan**.
4. **Terima kritik dengan lapang dada**.
5. **Selesaikan tugas tepat waktu**.
6. **Jaga sikap positif**.

### 6.4 Etika Profesional di Bidang IT

#### A. Apa Itu Etika Profesional?
**Etika profesional** adalah aturan moral dan perilaku yang harus diikuti dalam bekerja. Di bidang IT, etika sangat penting karena menyangkut data dan privasi orang lain.

#### B. Prinsip Etika di Bidang IT
| Prinsip | Penjelasan | Contoh Pelanggaran |
|---------|------------|-------------------|
| **Kejujuran** | Jujur dalam pekerjaan | Berbohong tentang progress proyek |
| **Privasi** | Menjaga kerahasiaan data | Membagikan data pelanggan |
| **Integritas** | Tidak korupsi/menyalahgunakan | Menggunakan akses untuk keuntungan pribadi |
| **Profesionalisme** | Bertindak profesional | Datang terlambat, tidak sopan |
| **Tanggung Jawab** | Bertanggung jawab atas pekerjaan | Menyalahkan orang lain |

#### C. Kode Etik di Bidang IT
1. **Jangan membajak software** - Gunakan software berlisensi.
2. **Jangan menyebarkan virus/malware**.
3. **Jangan mengakses data tanpa izin**.
4. **Jangan menyebarkan hoax/berita palsu**.
5. **Jaga kerahasiaan password**.
6. **Laporkan jika ada celah keamanan**.

#### D. Contoh Kasus Etika
**Kasus 1: Data Pelanggan Bocor**
- Seorang programmer memiliki akses ke database pelanggan.
- Tanpa izin, ia menjual data tersebut ke pihak lain.
- **Pelanggaran**: Privasi, integritas
- **Sanksi**: Dipecat, tuntutan hukum

**Kasus 2: Software Bajakan**
- Sebuah perusahaan menggunakan software bajakan.
- Mereka tidak mau membeli lisensi resmi.
- **Pelanggaran**: Hak cipta, profesionalisme
- **Sanksi**: Denda besar, tuntutan hukum

### 6.5 Pengenalan Agile dan Scrum

#### A. Apa Itu Agile?
**Agile** adalah cara/metodologi pengembangan perangkat lunak yang menekankan pada:
- **Iterasi pendek** (2-4 minggu)
- **Respons cepat** terhadap perubahan
- **Kolaborasi** dengan klien
- **Perangkat lunak yang berfungsi** (bukan dokumentasi yang sempurna)

**Agile Manifesto** (4 nilai utama):
1. **Individu dan interaksi** lebih penting dari proses dan alat.
2. **Perangkat lunak yang berfungsi** lebih penting dari dokumentasi.
3. **Kolaborasi dengan klien** lebih penting dari negosiasi kontrak.
4. **Merespons perubahan** lebih penting dari mengikuti rencana.

#### B. Apa Itu Scrum?
**Scrum** adalah framework Agile yang paling populer.

**Peran dalam Scrum**:
| Peran | Tugas |
|-------|-------|
| **Product Owner** | Menentukan fitur yang akan dibuat (prioritas) |
| **Scrum Master** | Memastikan Scrum berjalan dengan baik, menghilangkan hambatan |
| **Development Team** | Mengembangkan produk (3-9 orang) |

**Artefak Scrum**:
1. **Product Backlog**: Daftar semua fitur yang diinginkan.
2. **Sprint Backlog**: Fitur yang akan dikerjakan dalam 1 sprint.
3. **Increment**: Hasil kerja yang siap dikirim.

**Event Scrum**:
1. **Sprint** (2-4 minggu): Periode pengembangan.
2. **Sprint Planning**: Menentukan apa yang akan dikerjakan.
3. **Daily Standup** (15 menit): Update harian (3 pertanyaan).
4. **Sprint Review**: Presentasi hasil ke stakeholder.
5. **Sprint Retrospective**: Refleksi tim untuk perbaikan.

#### C. Contoh Penerapan Scrum di Sekolah
**Proyek: Membuat Aplikasi Kasir**

| Event | Penerapan |
|-------|-----------|
| Product Backlog | Fitur: Login, Transaksi, Laporan, Logout |
| Sprint Planning | Sprint 1 (2 minggu): Login + Transaksi |
| Daily Standup | Setiap pagi: "Kemarin saya..., hari ini saya..., hambatan..." |
| Sprint Review | Presentasi hasil ke guru |
| Sprint Retrospective | Diskusi: apa yang berjalan baik, apa yang perlu diperbaiki |

## BAB 7: JARINGAN KOMPUTER LANJUTAN

### 7.1 Routing dan Switching Dasar

#### A. Apa Itu Routing?
**Routing** adalah proses menentukan jalur terbaik untuk mengirimkan data dari satu jaringan ke jaringan lain.

**Ilustrasi Routing**:
```
+----------+    +----------+    +----------+
| Komputer | -- | Router A | -- | Router B | -- Internet
| A        |    | (LAN 1)  |    | (LAN 2)  |
+----------+    +----------+    +----------+
```
- Komputer A ingin mengakses internet.
- Data dikirim ke Router A.
- Router A menentukan jalur terbaik → Router B.
- Router B meneruskan ke internet.

#### B. Jenis Routing
| Jenis | Penjelasan | Kelebihan | Kekurangan |
|-------|------------|-----------|------------|
| **Static Routing** | Routing manual (dikonfigurasi admin) | Aman, tidak ada overhead | Tidak fleksibel (perlu update manual) |
| **Dynamic Routing** | Routing otomatis (protokol) | Otomatis adaptasi, fleksibel | Overhead, kompleks |

**Contoh Static Routing (Cisco)**:
```cisco
ip route 192.168.2.0 255.255.255.0 10.0.0.2
```

**Contoh Dynamic Routing (OSPF)**:
```cisco
router ospf 1
network 192.168.1.0 0.0.0.255 area 0
```

#### C. Apa Itu Switching?
**Switching** adalah proses meneruskan data (frame) dari satu perangkat ke perangkat lain di dalam jaringan yang sama.

**Ilustrasi Switching**:
```
+----------+    +----------+    +----------+
| Komputer |    | Switch   |    | Komputer |
| A        |----|          |----| B        |
+----------+    +----------+    +----------+
                    |
                +----------+
                | Printer  |
                +----------+
```

- Switch menerima data dari Komputer A.
- Switch mengetahui MAC address tujuan.
- Switch mengirim data hanya ke Komputer B (bukan ke semua).

#### D. Perbedaan Router dan Switch
| Aspek | Router | Switch |
|-------|--------|--------|
| Layer | Layer 3 (Network) | Layer 2 (Data Link) |
| Alamat | IP Address | MAC Address |
| Fungsi | Menghubungkan jaringan berbeda | Menghubungkan perangkat dalam 1 jaringan |
| Contoh | Menghubungkan LAN ke internet | Menghubungkan komputer dalam lab |

### 7.2 VLAN (Virtual Local Area Network)

#### A. Apa Itu VLAN?
**VLAN (Virtual LAN)** adalah cara membagi satu switch fisik menjadi beberapa jaringan virtual yang terisolasi.

**Ilustrasi VLAN**:
```
+--------------------------------------------------+
|  Switch 24 port                                   |
|                                                   |
|  VLAN 10 (IT)        VLAN 20 (Finance)            |
|  Port 1-8            Port 9-16                    |
|  Komputer IT 1-8     Komputer Finance 1-8         |
|                                                   |
|  VLAN 30 (Guest)     VLAN 40 (Server)             |
|  Port 17-20          Port 21-24                   |
|  Guest WiFi          Server Database              |
+--------------------------------------------------+
```

#### B. Manfaat VLAN
| Manfaat | Penjelasan |
|---------|------------|
| **Keamanan** | Memisahkan departemen (IT, Finance, Guest) |
| **Performance** | Mengurangi broadcast domain |
| **Fleksibilitas** | Perubahan mudah tanpa kabel ulang |
| **Manajemen** | Segmentasi berdasarkan fungsi |

#### C. Jenis VLAN
| VLAN ID | Nama | Fungsi |
|---------|------|--------|
| 1 | Default VLAN | Default, semua port di sini |
| 10 | VLAN IT | Perangkat IT |
| 20 | VLAN Finance | Perangkat Finance |
| 30 | VLAN Guest | Tamu (terisolasi) |
| 999 | Native VLAN | VLAN tanpa tag |

#### D. Konfigurasi VLAN di Cisco
```cisco
# Membuat VLAN
Switch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name IT
Switch(config-vlan)# exit

# Menambahkan port ke VLAN
Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# end

# Konfigurasi Trunk (untuk switch ke switch)
Switch(config)# interface fastEthernet 0/24
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30
```

#### E. Praktik VLAN di Cisco Packet Tracer
**Skenario**: Membangun jaringan dengan 2 departemen (IT dan Finance).

**Langkah**:
1. Buka Cisco Packet Tracer.
2. Tambahkan 1 switch dan 4 PC.
3. Hubungkan PC ke switch.
4. Konfigurasi VLAN:
   - VLAN 10: PC 1-2 (IT)
   - VLAN 20: PC 3-4 (Finance)
5. Test: PC IT tidak bisa ping ke PC Finance.

### 7.3 DHCP Server dan Konfigurasi

#### A. Apa Itu DHCP?
**DHCP (Dynamic Host Configuration Protocol)** adalah protokol yang memberikan IP address secara otomatis ke perangkat di jaringan.

**Manfaat DHCP**:
- Tidak perlu setting IP manual.
- Mengurangi kesalahan konfigurasi.
- Mudah menambah perangkat baru.

#### B. Proses DHCP (DORA)
```
+--------+                      +--------+
| Client |                      | Server |
+--------+                      +--------+
    |                                |
    | --- DHCPDISCOVER ------------> |  (Cari server DHCP)
    |                                |
    | <--- DHCPOFFER --------------- |  (Server menawarkan IP)
    |                                |
    | --- DHCPREQUEST -------------> |  (Client meminta IP)
    |                                |
    | <--- DHCPACK ---------------- |  (Server memberikan IP)
    |                                |
```

#### C. Konfigurasi DHCP di Router MikroTik
```mikrotik
# DHCP Server di MikroTik
/ip pool add name=dhcp-pool ranges=192.168.1.10-192.168.1.100
/ip dhcp-server add name=dhcp1 interface=bridge-local address-pool=dhcp-pool
/ip dhcp-server network add address=192.168.1.0/24 gateway=192.168.1.1 dns-server=8.8.8.8
```

#### D. Konfigurasi DHCP di Cisco
```cisco
# Membuat DHCP Pool
Router> enable
Router# configure terminal
Router(config)# ip dhcp pool LAN
```

### 7.5 NAT (Network Address Translation)

#### A. Apa Itu NAT?
**NAT (Network Address Translation)** adalah teknik menerjemahkan IP address private (di dalam jaringan) menjadi IP address public (di internet).

**Ilustrasi NAT**:
```
+----------+    +----------+    +----------+
| Komputer |    | Router   |    | Internet |

                +----------+
```

#### B. Jenis NAT

|-------|-----------|--------|
| **Static NAT** | 1 IP private → 1 IP public (1:1) | Server publik |

#### C. Manfaat NAT
1. **Menghemat IP public** - 1 IP public bisa dipakai banyak komputer.
2. **Keamanan** - IP private tidak terlihat dari internet.
3. **Fleksibilitas** - Bisa mengganti ISP tanpa mengubah IP internal.

### 7.6 Keamanan Jaringan Dasar (Firewall)

### 8.3 Sorting (Pengurutan) - Bubble, Selection, Insertion

#### A. Bubble Sort
Bubble sort membandingkan dua elemen yang berdekatan dan menukar jika urutannya salah.

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        # Flag untuk optimasi
        swapped = False
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr

# Contoh
data = [64, 34, 25, 12, 22, 11, 90]
print("Sebelum sorting:", data)
bubble_sort(data)
print("Setelah sorting:", data)
# Output: [11, 12, 22, 25, 34, 64, 90]
```

**Ilustrasi Bubble Sort**:
```
[64, 34, 25, 12, 22, 11, 90]
Iterasi 1:
[34, 64, 25, 12, 22, 11, 90]  (64 > 34, swap)
[34, 25, 64, 12, 22, 11, 90]  (64 > 25, swap)
[34, 25, 12, 64, 22, 11, 90]  (64 > 12, swap)
[34, 25, 12, 22, 64, 11, 90]  (64 > 22, swap)
[34, 25, 12, 22, 11, 64, 90]  (64 > 11, swap)
[34, 25, 12, 22, 11, 64, 90]  (64 < 90, no swap)
...
```

#### B. Selection Sort
Selection sort mencari elemen terkecil dan menukarnya dengan elemen pertama.

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        # Cari elemen terkecil di sisa array
        min_idx = i
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # Tukar dengan elemen ke-i
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# Contoh
data = [64, 34, 25, 12, 22, 11, 90]
selection_sort(data)
print(data)  # [11, 12, 22, 25, 34, 64, 90]
```

**Ilustrasi Selection Sort**:
```
[64, 34, 25, 12, 22, 11, 90]
Iterasi 1: cari terkecil = 11 → [11, 34, 25, 12, 22, 64, 90]
Iterasi 2: cari terkecil = 12 → [11, 12, 25, 34, 22, 64, 90]
Iterasi 3: cari terkecil = 22 → [11, 12, 22, 34, 25, 64, 90]
Iterasi 4: cari terkecil = 25 → [11, 12, 22, 25, 34, 64, 90]
...
```

#### C. Insertion Sort
Insertion sort seperti mengurutkan kartu di tangan.

```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        # Pindahkan elemen yang lebih besar ke kanan
        while j >= 0 and arr[j] > key:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key
    return arr

# Contoh
data = [64, 34, 25, 12, 22, 11, 90]
insertion_sort(data)
print(data)  # [11, 12, 22, 25, 34, 64, 90]
```

**Ilustrasi Insertion Sort**:
```
[64, 34, 25, 12, 22, 11, 90]
Iterasi 1: key=34 → [34, 64, 25, 12, 22, 11, 90]
Iterasi 2: key=25 → [25, 34, 64, 12, 22, 11, 90]
Iterasi 3: key=12 → [12, 25, 34, 64, 22, 11, 90]
Iterasi 4: key=22 → [12, 22, 25, 34, 64, 11, 90]
Iterasi 5: key=11 → [11, 12, 22, 25, 34, 64, 90]
...
```

#### D. Perbandingan Sorting
| Algoritma | Terbaik | Rata-rata | Terburuk | Memori |
|-----------|---------|-----------|----------|--------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |

### 8.4 Searching (Pencarian) - Linear dan Binary

#### A. Linear Search (Pencarian Linear)
Linear search mencari dengan memeriksa setiap elemen satu per satu.

```python
def linear_search(arr, target):
    for i, val in enumerate(arr):
        if val == target:
            return i  # Kembalikan indeks
    return -1  # Tidak ditemukan

# Contoh
data = [10, 20, 30, 40, 50, 60, 70]
hasil = linear_search(data, 40)
print(f"40 ditemukan di indeks: {hasil}")  # 3

hasil = linear_search(data, 99)
print(f"99 ditemukan di indeks: {hasil}")  # -1
```

**Ilustrasi Linear Search**:
```
Cari 40 di [10, 20, 30, 40, 50, 60, 70]
[10] → bukan 40
[20] → bukan 40
[30] → bukan 40
[40] → KETEMU! (indeks 3)
```

#### B. Binary Search (Pencarian Biner)
Binary search mencari dengan membagi data menjadi dua bagian (hanya bisa di data yang sudah terurut).

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1  # Tidak ditemukan

# Contoh
data = [10, 20, 30, 40, 50, 60, 70]  # Harus sudah terurut!
hasil = binary_search(data, 40)
print(f"40 ditemukan di indeks: {hasil}")  # 3

hasil = binary_search(data, 99)
print(f"99 ditemukan di indeks: {hasil}")  # -1
```

**Ilustrasi Binary Search**:
```
Cari 40 di [10, 20, 30, 40, 50, 60, 70]
low=0, high=6, mid=3 → arr[3]=40 → KETEMU! (indeks 3)

Cari 20 di [10, 20, 30, 40, 50, 60, 70]
low=0, high=6, mid=3 → arr[3]=40 (20 < 40) → high=2
low=0, high=2, mid=1 → arr[1]=20 → KETEMU! (indeks 1)
```

#### C. Perbandingan Linear vs Binary
| Aspek | Linear Search | Binary Search |
|-------|---------------|---------------|
| Data | Tidak perlu terurut | Harus terurut |
| Kompleksitas | O(n) | O(log n) |
| Kecepatan | Lambat untuk data besar | Cepat untuk data besar |
| Implementasi | Sederhana | Sedikit lebih kompleks |

### 8.5 Rekursi (Fungsi Rekursif)

#### A. Apa Itu Rekursi?
**Rekursi** adalah fungsi yang memanggil dirinya sendiri.

**Komponen Rekursi**:
1. **Base Case** - Kondisi untuk berhenti (tidak memanggil diri sendiri).
2. **Recursive Case** - Panggilan ke diri sendiri dengan masalah yang lebih kecil.

#### B. Contoh: Faktorial
```python
def faktorial(n):
    if n <= 1:  # Base case
        return 1
    return n * faktorial(n-1)  # Recursive case

# Trace
# faktorial(5) = 5 * faktorial(4)
#              = 5 * 4 * faktorial(3)
#              = 5 * 4 * 3 * faktorial(2)
#              = 5 * 4 * 3 * 2 * faktorial(1)
#              = 5 * 4 * 3 * 2 * 1
#              = 120

print(faktorial(5))  # 120
```

**Visualisasi Rekursi**:
```
faktorial(5)
    └── 5 * faktorial(4)
            └── 4 * faktorial(3)
                    └── 3 * faktorial(2)
                            └── 2 * faktorial(1)
                                    └── 1 (base case)
```

#### C. Contoh: Deret Fibonacci
```python
def fibonacci(n):
    if n <= 1:  # Base case
        return n
    return fibonacci(n-1) + fibonacci(n-2)  # Recursive case

# Trace
# fibonacci(5) = fibonacci(4) + fibonacci(3)
#              = (fibonacci(3) + fibonacci(2)) + (fibonacci(2) + fibonacci(1))
#              = ...
#              = 5

print(fibonacci(5))  # 5
```

#### D. Contoh: Menghitung Pangkat
```python
def pangkat(angka, pangkat):
    if pangkat == 0:  # Base case
        return 1
    return angka * pangkat(angka, pangkat-1)  # Recursive case

print(pangkat(2, 3))  # 8
print(pangkat(5, 0))  # 1
```

#### E. Kelebihan dan Kekurangan Rekursi
| Kelebihan | Kekurangan |
|-----------|------------|
| Kode lebih sederhana dan elegan | Menggunakan banyak memori (stack) |
| Cocok untuk masalah yang bisa dipecah | Bisa menyebabkan stack overflow |
| Mudah dipahami untuk masalah tertentu | Lebih lambat dari iterasi |

### 8.8 Proyek: Aplikasi Manajemen Data dengan File

**Tujuan**: Membuat aplikasi manajemen data siswa dengan penyimpanan file CSV.

**Fitur**:
1. Tambah data siswa
2. Lihat semua siswa
3. Cari siswa
4. Update data siswa
5. Hapus siswa
6. Simpan ke file
7. Muat dari file

**Implementasi**:
```python
import csv
import os

class ManajemenSiswa:
    def __init__(self, filename="siswa.csv"):
        self.filename = filename
        self.siswa = []
        self.load_data()

    def load_data(self):
        """Muat data dari file CSV"""
        if os.path.exists(self.filename):
            with open(self.filename, "r") as file:
                reader = csv.DictReader(file)
                self.siswa = list(reader)
            print(f"Data berhasil dimuat dari {self.filename}")
        else:
            print(f"File {self.filename} tidak ditemukan, data baru dibuat")
            self.siswa = []

    def save_data(self):
        """Simpan data ke file CSV"""
        with open(self.filename, "w", newline="") as file:
            fieldnames = ["nis", "nama", "kelas", "jurusan"]
            writer = csv.DictWriter(file, fieldnames=fieldnames)
            writer.writeheader()
            writer.writerows(self.siswa)
        print(f"Data berhasil disimpan ke {self.filename}")

    def tambah_siswa(self):
        """Tambah data siswa baru"""
        nis = input("NIS: ")
        nama = input("Nama: ")
        kelas = input("Kelas: ")
        jurusan = input("Jurusan: ")

        # Cek duplikat NIS
        for s in self.siswa:
            if s["nis"] == nis:
                print("Error: NIS sudah terdaftar!")
                return

        siswa_baru = {
            "nis": nis,
            "nama": nama,
            "kelas": kelas,
            "jurusan": jurusan
        }
        self.siswa.append(siswa_baru)
        self.save_data()
        print(f"Siswa {nama} berhasil ditambahkan!")

    def lihat_siswa(self):
        """Tampilkan semua siswa"""
        if not self.siswa:
            print("Belum ada data siswa.")
            return

        print("\n" + "=" * 60)
        print(f"{'NIS':<10} {'Nama':<15} {'Kelas':<10} {'Jurusan':<15}")
        print("-" * 60)
        for s in self.siswa:
            print(f"{s['nis']:<10} {s['nama']:<15} {s['kelas']:<10} {s['jurusan']:<15}")
        print("=" * 60)
        print(f"Total: {len(self.siswa)} siswa")

    def cari_siswa(self):
        """Cari siswa berdasarkan NIS atau nama"""
        keyword = input("Masukkan NIS atau nama yang dicari: ")
        hasil = []
        for s in self.siswa:
            if keyword.lower() in s["nis"].lower() or keyword.lower() in s["nama"].lower():
                hasil.append(s)

        if not hasil:
            print(f"Data dengan '{keyword}' tidak ditemukan.")
        else:
            print(f"\n--- Hasil pencarian '{keyword}' ---")
            for s in hasil:
                print(f"NIS: {s['nis']}, Nama: {s['nama']}, Kelas: {s['kelas']}, Jurusan: {s['jurusan']}")

    def update_siswa(self):
        """Update data siswa"""
        nis = input("Masukkan NIS siswa yang akan diupdate: ")
        for s in self.siswa:
            if s["nis"] == nis:
                print(f"Update data siswa: {s['nama']}")
                nama = input(f"Nama baru ({s['nama']}): ") or s['nama']
                kelas = input(f"Kelas baru ({s['kelas']}): ") or s['kelas']
                jurusan = input(f"Jurusan baru ({s['jurusan']}): ") or s['jurusan']

                s["nama"] = nama
                s["kelas"] = kelas
                s["jurusan"] = jurusan
                self.save_data()
                print("Data berhasil diupdate!")
                return

        print(f"Siswa dengan NIS {nis} tidak ditemukan!")

    def hapus_siswa(self):
        """Hapus data siswa"""
        nis = input("Masukkan NIS siswa yang akan dihapus: ")
        for i, s in enumerate(self.siswa):
            if s["nis"] == nis:
                konfirmasi = input(f"Yakin hapus {s['nama']}? (y/n): ")
                if konfirmasi.lower() == "y":
                    self.siswa.pop(i)
                    self.save_data()
                    print("Data berhasil dihapus!")
                else:
                    print("Penghapusan dibatalkan.")
                return

        print(f"Siswa dengan NIS {nis} tidak ditemukan!")

def main():
    app = ManajemenSiswa()

    while True:
        print("\n" + "=" * 40)
        print("SISTEM MANAJEMEN SISWA")
        print("=" * 40)
        print("1. Tambah Siswa")
        print("2. Lihat Semua Siswa")
        print("3. Cari Siswa")
        print("4. Update Siswa")
        print("5. Hapus Siswa")
        print("6. Keluar")
        print("-" * 40)

        pilihan = input("Pilih menu (1-6): ")

        if pilihan == "1":
            app.tambah_siswa()
        elif pilihan == "2":
            app.lihat_siswa()
        elif pilihan == "3":
            app.cari_siswa()
        elif pilihan == "4":
            app.update_siswa()
        elif pilihan == "5":
            app.hapus_siswa()
        elif pilihan == "6":
            print("Terima kasih!")
            break
        else:
            print("Pilihan tidak valid!")

if __name__ == "__main__":
    main()
```

### 9.1 Pewarisan (Inheritance) dan Hierarki Kelas

#### A. Pewarisan Lanjutan
Pewarisan memungkinkan sebuah kelas mewarisi atribut dan metode dari kelas lain. Ini membuat kode lebih terstruktur dan reusable.

#### B. Hierarki Kelas
```
+-------------------+
|   Hewan (Parent)  |
|  - nama, umur     |
|  - suara()        |
+-------------------+
        |
+-------+-------+
|               |
+-------+   +-------+

| = Meong|   | = Guk |
+-------+   +-------+
        |
+-------+

+-------+
```

#### C. Contoh Pewarisan Multi-Level

```python
class Kucing(Mamalia):

    def suara(self):
        return "Meong!"

        return f"Nama: {self.nama}, Jenis: {self.jenis}, Ras: {self.ras}, Habitat: {self.habitat}"

# Penggunaan

print(kucing.menyusui())  # Menyusui anaknya

```

### 9.2 Polimorfisme (Overriding dan Overloading)

#### A. Apa Itu Polimorfisme?
**Polimorfisme** (banyak bentuk) adalah kemampuan objek untuk memiliki banyak bentuk. Dalam OOP, polimorfisme memungkinkan method yang sama tetapi perilaku berbeda.

#### B. Overriding (Dynamic Polymorphism)
Overriding adalah kemampuan subclass untuk mengganti implementasi method dari parent class.

```python
class Shape:
    def luas(self):
        return 0

class Persegi(Shape):
    def __init__(self, sisi):
        self.sisi = sisi

    def luas(self):  # Override
        return self.sisi ** 2

class Lingkaran(Shape):
    def __init__(self, radius):
        self.radius = radius

    def luas(self):  # Override
        return 3.14 * self.radius ** 2

class Segitiga(Shape):
    def __init__(self, alas, tinggi):
        self.alas = alas
        self.tinggi = tinggi

    def luas(self):  # Override
        return 0.5 * self.alas * self.tinggi

# Polimorfisme
bentuk = [Persegi(5), Lingkaran(7), Segitiga(4, 6)]
for b in bentuk:
    print(f"Luas: {b.luas()}")  # Method yang sama, hasil berbeda
```

#### C. Overloading (Static Polymorphism)
Overloading adalah kemampuan untuk memiliki method dengan nama yang sama tetapi parameter berbeda.

**Python tidak mendukung overloading secara langsung, tapi bisa menggunakan default parameter atau *args**.

```python
class Calculator:
    # Overloading dengan default parameter
    def tambah(self, a, b, c=0):
        return a + b + c

    # Overloading dengan *args
    def tambah_many(self, *args):
        return sum(args)

calc = Calculator()
print(calc.tambah(5, 3))       # 8
print(calc.tambah(5, 3, 2))    # 10
print(calc.tambah_many(1, 2, 3, 4, 5))  # 15
```

**Overloading di Java (contoh)**:
```java
class Calculator {
    public int tambah(int a, int b) {
        return a + b;
    }

    public int tambah(int a, int b, int c) {
        return a + b + c;
    }

    public double tambah(double a, double b) {
        return a + b;
    }
}
```

### 9.3 Abstraksi dan Interface Dasar

#### A. Apa Itu Abstraksi?
**Abstraksi** adalah menyembunyikan detail implementasi dan hanya menampilkan fungsionalitas yang penting. Dalam OOP, abstraksi dicapai dengan abstract class dan interface.

#### B. Abstract Class di Python
Abstract class adalah kelas yang tidak bisa diinstansiasi dan hanya berfungsi sebagai template.

```python
from abc import ABC, abstractmethod

class Kendaraan(ABC):
    @abstractmethod
    def bergerak(self):
        pass

    @abstractmethod
    def info(self):
        pass

    def deskripsi(self):  # Method konkret
        return "Ini adalah kendaraan"

class Mobil(Kendaraan):
    def bergerak(self):
        return "Mobil bergerak di jalan"

    def info(self):
        return "Mobil: 4 roda, mesin bensin"

class Kapal(Kendaraan):
    def bergerak(self):
        return "Kapal berlayar di laut"

    def info(self):
        return "Kapal: berlayar, menggunakan bahan bakar"

# k = Kendaraan()  # ERROR: tidak bisa instansiasi abstract class

mobil = Mobil()
kapal = Kapal()
print(mobil.bergerak())  # Mobil bergerak di jalan
print(kapal.bergerak())  # Kapal berlayar di laut
print(mobil.deskripsi()) # Ini adalah kendaraan
```

#### C. Interface di Python (menggunakan ABC)
Interface adalah kontrak yang harus diimplementasikan oleh kelas.

```python
from abc import ABC, abstractmethod

class Terbang(ABC):
    @abstractmethod
    def terbang(self):
        pass

class Berenang(ABC):
    @abstractmethod
    def berenang(self):
        pass

class Bebek(Terbang, Berenang):
    def terbang(self):
        return "Bebek terbang"

    def berenang(self):
        return "Bebek berenang"

class Pesawat(Terbang):
    def terbang(self):
        return "Pesawat terbang di langit"

# Penggunaan
bebek = Bebek()
pesawat = Pesawat()
print(bebek.terbang())  # Bebek terbang
print(bebek.berenang()) # Bebek berenang
print(pesawat.terbang()) # Pesawat terbang di langit
```

#### D. Manfaat Abstraksi
1. **Menyembunyikan kompleksitas** - Pengguna hanya melihat fungsionalitas yang penting.
2. **Memudahkan perubahan** - Detail implementasi bisa diubah tanpa mengganggu pengguna.
3. **Meningkatkan keamanan** - Data sensitif tidak diekspos langsung.
4. **Menciptakan standar** - Semua subclass harus mengikuti kontrak yang ditentukan.

### 9.4 Relasi Antar Kelas (Asosiasi, Agregasi, Komposisi)

#### A. Asosiasi (Association)
**Asosiasi** adalah hubungan antar objek yang saling mengenal tetapi independen.

```python
class Dosen:
    def __init__(self, nama):
        self.nama = nama

class Mahasiswa:
    def __init__(self, nama):
        self.nama = nama
        self.dosen = None

    def set_dosen(self, dosen):
        self.dosen = dosen

# Penggunaan
dosen = Dosen("Pak Budi")

print(f"{mhs.nama} dosennya {mhs.dosen.nama}")
```

### 9.5 Exception Handling di OOP

#### A. Custom Exception di OOP
Kita bisa membuat exception khusus untuk kelas kita.

```python
class BankAccount:
    class SaldoTidakCukupError(Exception):
        pass

    class JumlahNegatifError(Exception):
        pass

    def __init__(self, pemilik, saldo):
        self.pemilik = pemilik
        self.saldo = saldo

    def tarik(self, jumlah):
        if jumlah < 0:
            raise self.JumlahNegatifError("Jumlah tidak boleh negatif!")
        if jumlah > self.saldo:
            raise self.SaldoTidakCukupError(f"Saldo {self.saldo} tidak cukup untuk tarik {jumlah}")
        self.saldo -= jumlah
        print(f"Tarik {jumlah} berhasil. Saldo: {self.saldo}")

    def setor(self, jumlah):
        if jumlah < 0:
            raise self.JumlahNegatifError("Jumlah tidak boleh negatif!")
        self.saldo += jumlah
        print(f"Setor {jumlah} berhasil. Saldo: {self.saldo}")

# Penggunaan
akun = BankAccount("Budi", 1000)

try:
    akun.tarik(500)
    akun.tarik(600)  # Error
except BankAccount.SaldoTidakCukupError as e:
    print(f"Error: {e}")
except BankAccount.JumlahNegatifError as e:
    print(f"Error: {e}")
```

### 9.7 Proyek: Sistem Manajemen Perpustakaan dengan OOP

**Tujuan**: Membangun sistem manajemen perpustakaan dengan OOP.

**Spesifikasi**:
1. Buku: ID, Judul, Penulis, Tahun, Stok.
2. Anggota: ID, Nama, Alamat.
3. Peminjaman: ID Buku, ID Anggota, Tanggal Pinjam.
4. Fitur: Tambah Buku, Daftar Buku, Pinjam Buku, Kembalikan Buku.

**Implementasi**:
```python
import datetime

class Buku:
    def __init__(self, id, judul, penulis, tahun, stok):
        self.id = id
        self.judul = judul
        self.penulis = penulis
        self.tahun = tahun
        self.stok = stok

    def info(self):
        return f"{self.id}. {self.judul} - {self.penulis} ({self.tahun}), Stok: {self.stok}"

    def tersedia(self):
        return self.stok > 0

class Anggota:
    def __init__(self, id, nama, alamat):
        self.id = id
        self.nama = nama
        self.alamat = alamat
        self.buku_dipinjam = []

    def pinjam(self, book_id):
        self.buku_dipinjam.append(book_id)

    def kembalikan(self, book_id):
        if book_id in self.buku_dipinjam:
            self.buku_dipinjam.remove(book_id)
            return True
        return False

class Perpustakaan:
    def __init__(self):
        self.buku = {}
        self.anggota = {}
        self.peminjaman = {}
        self.next_buku_id = 1
        self.next_anggota_id = 1
        self.next_pinjam_id = 1

    def tambah_buku(self, judul, penulis, tahun, stok):
        id = self.next_buku_id
        self.buku[id] = Buku(id, judul, penulis, tahun, stok)
        self.next_buku_id += 1
        print(f"Buku '{judul}' berhasil ditambahkan (ID: {id})")

    def daftar_buku(self):
        if not self.buku:
            print("Belum ada buku.")
            return
        print("\n" + "=" * 60)
        print("DAFTAR BUKU")
        print("-" * 60)
        for b in self.buku.values():
            print(b.info())
        print("=" * 60)

    def cari_buku(self, keyword):
        hasil = []
        for b in self.buku.values():
            if keyword.lower() in b.judul.lower() or keyword.lower() in b.penulis.lower():
                hasil.append(b)

        if not hasil:
            print(f"Buku dengan '{keyword}' tidak ditemukan.")
        else:
            print(f"\n--- Hasil pencarian '{keyword}' ---")
            for b in hasil:
                print(b.info())

    def tambah_anggota(self, nama, alamat):
        id = self.next_anggota_id
        self.anggota[id] = Anggota(id, nama, alamat)
        self.next_anggota_id += 1
        print(f"Anggota '{nama}' berhasil ditambahkan (ID: {id})")

    def daftar_anggota(self):
        if not self.anggota:
            print("Belum ada anggota.")
            return
        print("\n" + "=" * 50)
        print("DAFTAR ANGGOTA")
        print("-" * 50)
        for a in self.anggota.values():
            print(f"ID: {a.id}, Nama: {a.nama}, Alamat: {a.alamat}")
            if a.buku_dipinjam:
                print(f"  Meminjam: {', '.join(str(b) for b in a.buku_dipinjam)}")
        print("=" * 50)

    def pinjam_buku(self, book_id, member_id):
        if book_id not in self.buku:
            print(f"Buku ID {book_id} tidak ditemukan.")
            return
        if member_id not in self.anggota:
            print(f"Anggota ID {member_id} tidak ditemukan.")
            return

        buku = self.buku[book_id]
        if not buku.tersedia():
            print("Buku tidak tersedia.")
            return

        anggota = self.anggota[member_id]
        if len(anggota.buku_dipinjam) >= 3:
            print("Anggota sudah meminjam maksimal 3 buku.")
            return

        anggota.pinjam(book_id)
        buku.stok -= 1

        pinjam_id = self.next_pinjam_id
        tgl = datetime.date.today()
        self.peminjaman[pinjam_id] = {
            "id": pinjam_id,
            "book_id": book_id,
            "member_id": member_id,
            "tgl_pinjam": tgl,
            "tgl_kembali": None
        }
        self.next_pinjam_id += 1

        print(f"Buku '{buku.judul}' dipinjam oleh {anggota.nama} pada {tgl}")

    def kembalikan_buku(self, book_id, member_id):
        if book_id not in self.buku:
            print(f"Buku ID {book_id} tidak ditemukan.")
            return
        if member_id not in self.anggota:
            print(f"Anggota ID {member_id} tidak ditemukan.")
            return

        anggota = self.anggota[member_id]
        if not anggota.kembalikan(book_id):
            print(f"Buku ID {book_id} tidak dipinjam oleh {anggota.nama}")
            return

        buku = self.buku[book_id]
        buku.stok += 1

        tgl = datetime.date.today()
        for pinjam in self.peminjaman.values():
            if pinjam["book_id"] == book_id and pinjam["member_id"] == member_id and pinjam["tgl_kembali"] is None:
                pinjam["tgl_kembali"] = tgl
                break

        print(f"Buku '{buku.judul}' dikembalikan oleh {anggota.nama} pada {tgl}")

    def laporan_peminjaman(self):
        if not self.peminjaman:
            print("Belum ada peminjaman.")
            return
        print("\n" + "=" * 70)
        print("LAPORAN PEMINJAMAN")
        print("-" * 70)
        for p in self.peminjaman.values():
            buku = self.buku.get(p["book_id"], None)
            anggota = self.anggota.get(p["member_id"], None)
            judul = buku.judul if buku else "Tidak ditemukan"
            nama = anggota.nama if anggota else "Tidak ditemukan"
            status = "Belum kembali" if p["tgl_kembali"] is None else f"Kembali {p['tgl_kembali']}"
            print(f"ID: {p['id']}, Buku: {judul}, Anggota: {nama}, Pinjam: {p['tgl_pinjam']}, Status: {status}")
        print("=" * 70)

def main():
    lib = Perpustakaan()

    # Data awal
    lib.tambah_buku("Python Programming", "John Doe", 2020, 5)
    lib.tambah_buku("Java Programming", "Jane Smith", 2021, 3)
    lib.tambah_buku("Algoritma", "Budi", 2019, 4)
    lib.tambah_anggota("Budi", "Jl. Merdeka No. 1")
    lib.tambah_anggota("Ani", "Jl. Sudirman No. 5")

    while True:
        print("\n" + "=" * 40)
        print("SISTEM MANAJEMEN PERPUSTAKAAN")
        print("=" * 40)
        print("1. Daftar Buku")
        print("2. Cari Buku")
        print("3. Tambah Buku")
        print("4. Daftar Anggota")
        print("5. Tambah Anggota")
        print("6. Pinjam Buku")
        print("7. Kembalikan Buku")
        print("8. Laporan Peminjaman")
        print("9. Keluar")
        print("-" * 40)

        pilihan = input("Pilih menu (1-9): ")

        if pilihan == "1":
            lib.daftar_buku()
        elif pilihan == "2":
            keyword = input("Masukkan judul/penulis: ")
            lib.cari_buku(keyword)
        elif pilihan == "3":
            judul = input("Judul: ")
            penulis = input("Penulis: ")
            tahun = int(input("Tahun: "))
            stok = int(input("Stok: "))
            lib.tambah_buku(judul, penulis, tahun, stok)
        elif pilihan == "4":
            lib.daftar_anggota()
        elif pilihan == "5":
            nama = input("Nama: ")
            alamat = input("Alamat: ")
            lib.tambah_anggota(nama, alamat)
        elif pilihan == "6":
            book_id = int(input("ID Buku: "))
            member_id = int(input("ID Anggota: "))
            lib.pinjam_buku(book_id, member_id)
        elif pilihan == "7":
            book_id = int(input("ID Buku: "))
            member_id = int(input("ID Anggota: "))
            lib.kembalikan_buku(book_id, member_id)
        elif pilihan == "8":
            lib.laporan_peminjaman()
        elif pilihan == "9":

if __name__ == "__main__":
```

### 10.4 Proyek: Game Sederhana dengan Pygame

**Tujuan**: Membuat game "Space Shooter" sederhana di mana pemain mengendalikan pesawat dan menembak musuh.

**Spesifikasi**:
1. Player bergerak dengan arrow keys.
2. Menembak dengan spasi.
3. Musuh muncul dari atas layar.
4. Score bertambah saat musuh dihancurkan.
5. Game over jika player terkena musuh.

**Implementasi**:
```python
import pygame
import random
import sys

# Inisialisasi
pygame.init()

# Setup window
WIDTH = 800
HEIGHT = 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Space Shooter")

# Warna
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
RED = (255, 0, 0)
GREEN = (0, 255, 0)
BLUE = (0, 0, 255)

# Clock
clock = pygame.time.Clock()
FPS = 60

# Font
font = pygame.font.Font(None, 36)

# Player
class Player:
    def __init__(self):
        self.width = 40
        self.height = 40
        self.x = WIDTH // 2 - self.width // 2
        self.y = HEIGHT - 80
        self.speed = 5
        self.rect = pygame.Rect(self.x, self.y, self.width, self.height)

    def update(self):
        keys = pygame.key.get_pressed()
        if keys[pygame.K_LEFT] and self.x > 0:
            self.x -= self.speed
        if keys[pygame.K_RIGHT] and self.x < WIDTH - self.width:
            self.x += self.speed
        if keys[pygame.K_UP] and self.y > 0:
            self.y -= self.speed
        if keys[pygame.K_DOWN] and self.y < HEIGHT - self.height:
            self.y += self.speed
        self.rect.x = self.x
        self.rect.y = self.y

    def draw(self):
        pygame.draw.rect(screen, BLUE, self.rect)

# Bullet
class Bullet:
    def __init__(self, x, y):
        self.width = 5
        self.height = 10
        self.x = x + 17
        self.y = y
        self.speed = 8
        self.rect = pygame.Rect(self.x, self.y, self.width, self.height)

    def update(self):
        self.y -= self.speed
        self.rect.y = self.y

    def draw(self):
        pygame.draw.rect(screen, WHITE, self.rect)

# Enemy
class Enemy:
    def __init__(self):
        self.width = 30
        self.height = 30
        self.x = random.randint(0, WIDTH - self.width)
        self.y = -self.height
        self.speed = random.randint(2, 5)
        self.rect = pygame.Rect(self.x, self.y, self.width, self.height)

    def update(self):
        self.y += self.speed
        self.rect.y = self.y

    def draw(self):
        pygame.draw.rect(screen, RED, self.rect)

# Inisialisasi game
player = Player()
bullets = []
enemies = []
score = 0
enemy_timer = 0

# Game loop
running = True
while running:
    # Event handling
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                bullets.append(Bullet(player.x, player.y))

    # Update
    player.update()

    # Update bullets
    for bullet in bullets[:]:
        bullet.update()
        if bullet.y < 0:
            bullets.remove(bullet)

    # Spawn enemies
    enemy_timer += 1
    if enemy_timer > 30:
        enemies.append(Enemy())
        enemy_timer = 0

    # Update enemies
    for enemy in enemies[:]:
        enemy.update()
        if enemy.y > HEIGHT:
            enemies.remove(enemy)

    # Collision: bullets vs enemies
    for bullet in bullets[:]:
        for enemy in enemies[:]:
            if bullet.rect.colliderect(enemy.rect):
                bullets.remove(bullet)
                enemies.remove(enemy)
                score += 10
                break

    # Collision: player vs enemies
    for enemy in enemies:
        if player.rect.colliderect(enemy.rect):
            running = False

    # Render
    screen.fill(BLACK)

    player.draw()
    for bullet in bullets:
        bullet.draw()
    for enemy in enemies:
        enemy.draw()

    # Display score
    score_text = font.render(f"Score: {score}", True, WHITE)
    screen.blit(score_text, (10, 10))

    pygame.display.flip()
    clock.tick(FPS)

# Game Over
screen.fill(BLACK)
game_over_text = font.render("GAME OVER", True, RED)
score_text = font.render(f"Final Score: {score}", True, WHITE)
screen.blit(game_over_text, (WIDTH//2 - 80, HEIGHT//2 - 30))
screen.blit(score_text, (WIDTH//2 - 70, HEIGHT//2 + 10))
pygame.display.flip()

# Tunggu 3 detik
pygame.time.wait(3000)
pygame.quit()
sys.exit()
```
