## BAB 5: KECAKAPAN KERJA LANJUTAN

### 5.1 Manajemen Proyek Agile dan Scrum

#### A. Pengertian Manajemen Proyek
Manajemen proyek adalah proses perencanaan, pengorganisasian, dan pengelolaan sumber daya untuk mencapai tujuan proyek tertentu dengan batasan waktu, biaya, dan kualitas.

#### B. Agile Methodology
**Agile Manifesto** (2001, 17 pengembang):
1. **Individu dan interaksi** lebih penting daripada proses dan alat.
2. **Perangkat lunak yang berfungsi** lebih penting daripada dokumentasi yang lengkap.
3. **Kolaborasi dengan klien** lebih penting daripada negosiasi kontrak.
4. **Merespons perubahan** lebih penting daripada mengikuti rencana.

**Prinsip Agile** (12 prinsip):
1. Kepuasan pelanggan melalui pengiriman awal dan terus-menerus.
2. Menyambut perubahan, bahkan di akhir pengembangan.
3. Mengirimkan produk yang berfungsi secara berkala (minggu/bulan).
4. Kolaborasi harian antara bisnis dan pengembang.
5. Proyek dibangun di sekitar individu yang termotivasi.
6. Komunikasi tatap muka adalah yang paling efektif.
7. Kemajuan diukur berdasarkan perangkat lunak yang berfungsi.
8. Kecepatan berkelanjutan (sustainable pace) untuk tim.
9. Perhatian terus-menerus pada keunggulan teknis dan desain yang baik.
10. Kesederhanaan (memaksimalkan pekerjaan yang tidak dilakukan).
11. Tim yang mengorganisir diri sendiri menghasilkan arsitektur terbaik.
12. Refleksi dan penyesuaian secara teratur.

#### C. Scrum Framework
**Scrum** adalah framework Agile untuk mengelola pengembangan produk kompleks.

**Peran dalam Scrum**:
| Peran | Tanggung Jawab |
|-------|---------------|
| **Product Owner** | Mengelola Product Backlog, menentukan prioritas, menjadi jembatan dengan stakeholder |
| **Scrum Master** | Memastikan Scrum dijalankan dengan benar, menghilangkan hambatan, menjadi fasilitator |
| **Development Team** | Mengembangkan produk, self-organizing, cross-functional (3-9 orang) |

**Artifak Scrum**:
1. **Product Backlog**: Daftar semua fitur yang diinginkan (user stories).
2. **Sprint Backlog**: Fitur yang akan dikerjakan dalam 1 sprint.
3. **Increment**: Hasil kerja yang siap dikirim (potentially shippable).

**Event Scrum**:
1. **Sprint** (2-4 minggu): Periode pengembangan dengan output yang terukur.
2. **Sprint Planning**: Menentukan apa yang akan dikerjakan dalam sprint.
3. **Daily Standup** (15 menit): 3 pertanyaan: 
   - Apa yang saya kerjakan kemarin?
   - Apa yang akan saya kerjakan hari ini?
   - Ada hambatan?
4. **Sprint Review**: Presentasi hasil sprint ke stakeholder.
5. **Sprint Retrospective**: Refleksi tim untuk perbaikan.

#### D. User Stories dan Acceptance Criteria
**User Story** format:
```
Sebagai [peran], saya ingin [fitur] sehingga [manfaat].
```

Contoh:
```
Sebagai pengguna, saya ingin bisa login dengan email dan password sehingga data saya aman.
```

**INVEST Criteria** (untuk user story yang baik):
- **I**ndependent (independen)
- **N**egotiable (dapat dinegosiasikan)
- **V**aluable (ber nilai)
- **E**stimable (dapat diestimasi)
- **S**mall (kecil)
- **T**estable (dapat diuji)

**Acceptance Criteria**:
```
Scenario: Login sukses
Given: Pengguna berada di halaman login
When: Pengguna memasukkan email dan password yang benar
Then: Pengguna diarahkan ke halaman dashboard
```

#### E. Estimasi dan Velocity
**Estimasi menggunakan Planning Poker**:
- Memberi skor (Fibonacci: 1,2,3,5,8,13,21) untuk setiap user story.
- Diskusi jika ada perbedaan, lalu voting ulang.

**Velocity**:
- Rata-rata story points yang diselesaikan per sprint.
- Digunakan untuk memprediksi kapasitas sprint berikutnya.

**Contoh**:
- Sprint 1: 30 story points
- Sprint 2: 25 story points
- Sprint 3: 35 story points
- Velocity rata-rata: 30 story points/sprint

### 5.2 DevOps dan Continuous Integration/Deployment

#### A. Definisi DevOps
DevOps adalah budaya, filosofi, dan praktik yang menggabungkan pengembangan (Development) dan operasi (Operations) untuk meningkatkan kolaborasi dan produktivitas dengan cara mengotomatisasi proses.

**Tujuan DevOps**:
- Mengurangi waktu pengiriman (lead time).
- Meningkatkan frekuensi deployment.
- Mengurangi kegagalan deployment.
- Mempercepat pemulihan dari kegagalan.

#### B. Prinsip DevOps (CALMS)
| Prinsip | Penjelasan |
|---------|------------|
| **Culture** | Budaya kolaborasi antar tim dev dan ops |
| **Automation** | Otomatisasi build, test, deployment |
| **Lean** | Mengurangi waste, fokus pada value |
| **Measurement** | Mengukur metrik (lead time, MTTR, deployment frequency) |
| **Sharing** | Berbagi pengetahuan dan tanggung jawab |

#### C. CI/CD Pipeline
**Continuous Integration (CI)**:
- Developer sering merge ke branch utama.
- Otomatisasi build dan test.
- Tujuannya: mendeteksi error lebih awal.

**Continuous Delivery (CD)**:
- Setiap perubahan siap di-deploy ke produksi.
- Deployment masih manual (approval).

**Continuous Deployment (CD)**:
- Setiap perubahan otomatis di-deploy ke produksi.

**Pipeline CI/CD**:
```
+----------+    +----------+    +----------+    +----------+    +----------+
| Commit   | -> | Build    | -> | Test     | -> | Deploy   | -> | Monitor  |
| Code     |    | (Compile)|    | (Unit,   |    | (Staging |    | (Logs,   |
|          |    |          |    |  Integ)  |    | /Prod)   |    |  Metrics)|
+----------+    +----------+    +----------+    +----------+    +----------+
```

#### D. Tools DevOps
| Kategori | Tools |
|----------|-------|
| Source Control | Git, GitHub, GitLab, Bitbucket |
| CI/CD | Jenkins, GitHub Actions, GitLab CI, CircleCI, Travis CI |
| Container | Docker, Podman |
| Orchestration | Kubernetes (K8s), Docker Swarm |
| Configuration | Ansible, Terraform, Chef, Puppet |
| Monitoring | Prometheus, Grafana, ELK Stack, Datadog |
| Logging | ELK Stack, Splunk, Loki |
| Cloud | AWS, GCP, Azure |

#### E. Contoh Pipeline dengan GitHub Actions
```yaml
name: CI/CD Pipeline

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt
      
      - name: Lint with flake8
        run: |
          pip install flake8
          flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics
      
      - name: Test with pytest
        run: |
          pip install pytest
          pytest tests/ --cov=.
      
      - name: Build Docker image
        run: |
          docker build -t myapp:${{ github.sha }} .
      
      - name: Push to Docker Hub
        if: github.ref == 'refs/heads/main'
        run: |
          echo "${{ secrets.DOCKER_PASSWORD }}" | docker login -u "${{ secrets.DOCKER_USERNAME }}" --password-stdin
          docker tag myapp:${{ github.sha }} myuser/myapp:latest
          docker push myuser/myapp:latest
      
      - name: Deploy to production
        if: github.ref == 'refs/heads/main'
        run: |
          kubectl set image deployment/myapp myapp=myuser/myapp:latest
          kubectl rollout status deployment/myapp
```

### 5.3 Dokumentasi Teknis dan User Manual

#### A. Pentingnya Dokumentasi
Dokumentasi adalah bagian penting dari pengembangan perangkat lunak karena:
1. Mempermudah onboarding karyawan baru.
2. Menjadi referensi untuk maintenance dan debugging.
3. Memudahkan komunikasi antar tim.
4. Memenuhi kebutuhan regulasi dan audit.
5. Meningkatkan kualitas dan konsistensi produk.

#### B. Jenis-Jenis Dokumentasi
| Jenis | Tujuan | Contoh |
|-------|--------|--------|
| **Technical Documentation** | Untuk pengembang | API docs, architecture diagram, code comments |
| **User Documentation** | Untuk pengguna | User manual, FAQ, tutorial |
| **Operational Documentation** | Untuk tim ops | Runbook, playbook, disaster recovery plan |
| **Project Documentation** | Untuk manajemen | Project charter, meeting minutes, status report |

#### C. Dokumentasi Teknis
1. **README.md**:
   - Deskripsi proyek.
   - Instalasi dan setup.
   - Cara menjalankan aplikasi.
   - Daftar dependencies.
   - Kontribusi.

2. **API Documentation** (OpenAPI/Swagger):
```yaml
openapi: 3.0.0
info:
  title: User API

  /users:

                type: array
                items:
                  $ref: '#/components/schemas/User'
components:
  schemas:
    User:
      type: object
      properties:
        id:
          type: integer
        name:
          type: string
```

3. **Architecture Decision Records (ADR)**:
```
# ADR-001: Memilih PostgreSQL sebagai Database

## Context
Proyek membutuhkan database untuk menyimpan data pengguna dan transaksi.

## Decision
Kami memilih PostgreSQL karena:
- Mendukung ACID transactions

- Open source dan komunitas besar

## Consequences

- Tim perlu belajar SQL
- Migration tool diperlukan
```

## BAB 6: JARINGAN KOMPUTER LANJUTAN

### 6.1 Dynamic Routing Protocol (RIP, OSPF, EIGRP, BGP)

#### A. RIP (Routing Information Protocol)
**Karakteristik**:
- Distance Vector routing protocol.
- Metric: Hop count (maks 15 hop).
- Update period: 30 detik.
- V1: classful, V2: classless (supports VLSM).
- Administrative Distance: 120.

**Konfigurasi RIP v2 (Cisco)**:
```cisco
Router(config)# router rip
Router(config-router)# version 2
Router(config-router)# network 192.168.1.0
Router(config-router)# network 10.0.0.0
Router(config-router)# no auto-summary
```

#### B. OSPF (Open Shortest Path First)
**Karakteristik**:
- Link State routing protocol.
- Metric: Bandwidth (cost = 10^8 / bandwidth).
- Dijkstra algorithm (SPF).
- Area concept untuk scalability.
- Administrative Distance: 110.

**Hierarki OSPF**:
```
+-------------------+
|    Area 0         |  <- Backbone
|  (Backbone)       |
+--------+----------+
         |
+--------+----------+
|    Area 1         |  <- Non-backbone
|                   |
+--------+----------+
         |
+--------+----------+
|    Area 2         |  <- Non-backbone
|                   |
+--------+----------+
```

**Konfigurasi OSPF (Cisco)**:
```cisco
Router(config)# router ospf 1
Router(config-router)# network 192.168.1.0 0.0.0.255 area 0
Router(config-router)# network 10.0.0.0 0.255.255.255 area 1
Router(config-router)# router-id 1.1.1.1
```

#### C. EIGRP (Enhanced Interior Gateway Routing Protocol)
**Karakteristik**:
- Hybrid routing protocol (Cisco proprietary, sekarang open).
- Metric: Bandwidth + Delay + Load + Reliability.
- DUAL algorithm (Diffusing Update Algorithm).
- Fast convergence.
- Administrative Distance: 90.

**Konfigurasi EIGRP**:
```cisco
Router(config)# router eigrp 100
Router(config-router)# network 192.168.1.0 0.0.0.255
Router(config-router)# network 10.0.0.0 0.255.255.255
Router(config-router)# no auto-summary
```

#### D. BGP (Border Gateway Protocol)
**Karakteristik**:
- Path Vector routing protocol.
- Digunakan untuk routing antar AS (Autonomous System).
- Metric: Path attributes (AS Path, Local Preference, MED).
- Administrative Distance: 20 (eBGP), 200 (iBGP).

**BGP Path Selection** (11 langkah):
1. Highest Weight (Cisco proprietary)
2. Highest Local Preference
3. Prefer locally originated routes
4. Shortest AS Path
5. Lowest Origin Type (IGP < EGP < Incomplete)
6. Lowest MED (Multi-Exit Discriminator)
7. Prefer eBGP over iBGP
8. Lowest IGP metric to next hop
9. Prefer oldest path (iBGP)
10. Lowest Router ID
11. Minimum neighbor address

**Perbandingan Routing Protocol**:
| Aspek | RIP | OSPF | EIGRP | BGP |
|-------|-----|------|-------|-----|

### 7.1 Recursive Algorithms dan Backtracking

#### A. Recursive Algorithms - Mendalam
**Rekursi** adalah teknik di mana fungsi memanggil dirinya sendiri.

**Komponen Rekursi**:
1. **Base Case**: Kondisi untuk berhenti.
2. **Recursive Case**: Panggilan ke dirinya sendiri dengan masalah yang lebih kecil.

**Contoh: Factorial**
```python
def factorial(n):
    if n <= 1:          # Base case
        return 1
    return n * factorial(n-1)  # Recursive case

# Trace: factorial(5) = 5 * 4 * 3 * 2 * 1 = 120
```

**Contoh: Fibonacci**
```python
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# Trace: fibonacci(5) = 5
# Kompleksitas: O(2^n) - sangat lambat untuk n besar
```

**Tail Recursion** (optimasi):
```python
def factorial_tail(n, accumulator=1):
    if n <= 1:
        return accumulator
    return factorial_tail(n-1, n * accumulator)
```

#### B. Backtracking
**Backtracking** adalah teknik untuk mencari solusi dengan mencoba semua kemungkinan, dan mundur (backtrack) jika jalan buntu.

**Contoh: N-Queens Problem**
```python
def solve_n_queens(n):
    def is_safe(board, row, col):
        # Cek kolom
        for i in range(row):
            if board[i][col] == 1:
                return False
        # Cek diagonal kiri atas
        for i, j in zip(range(row-1, -1, -1), range(col-1, -1, -1)):
            if board[i][j] == 1:
                return False
        # Cek diagonal kanan atas
        for i, j in zip(range(row-1, -1, -1), range(col+1, n)):
            if board[i][j] == 1:
                return False
        return True

    def solve(board, row):
        if row >= n:  # Semua queen ditempatkan
            return True
        for col in range(n):
            if is_safe(board, row, col):
                board[row][col] = 1
                if solve(board, row + 1):
                    return True
                board[row][col] = 0  # Backtrack
        return False

    board = [[0] * n for _ in range(n)]
    solve(board, 0)
    return board

# Test: 8-Queens
solution = solve_n_queens(8)
for row in solution:
    print(row)
```

**Contoh: Sudoku Solver**
```python
def solve_sudoku(board):
    def is_valid(board, row, col, num):
        # Cek baris
        for j in range(9):
            if board[row][j] == num:
                return False
        # Cek kolom
        for i in range(9):
            if board[i][col] == num:
                return False
        # Cek box 3x3
        box_row, box_col = 3 * (row // 3), 3 * (col // 3)
        for i in range(box_row, box_row + 3):
            for j in range(box_col, box_col + 3):
                if board[i][j] == num:
                    return False
        return True

    def solve(board):
        for i in range(9):
            for j in range(9):
                if board[i][j] == 0:
                    for num in range(1, 10):
                        if is_valid(board, i, j, num):
                            board[i][j] = num
                            if solve(board):
                                return True
                            board[i][j] = 0  # Backtrack
                    return False
        return True

    solve(board)
    return board
```

### 7.2 Dynamic Programming

#### A. Definisi Dynamic Programming
Dynamic Programming (DP) adalah teknik untuk memecahkan masalah kompleks dengan membaginya menjadi sub-masalah yang lebih kecil, menyimpan hasil sub-masalah agar tidak dihitung ulang (memoization atau tabulation).

**Karakteristik DP**:
1. **Optimal Substructure**: Solusi optimal dari masalah dapat dibangun dari solusi optimal sub-masalah.
2. **Overlapping Subproblems**: Sub-masalah muncul berulang kali.

#### B. Pendekatan DP
1. **Top-Down (Memoization)**: Rekursif + cache.
2. **Bottom-Up (Tabulation)**: Iteratif + tabel.

**Contoh: Fibonacci dengan Memoization**
```python
def fib_memo(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib_memo(n-1, memo) + fib_memo(n-2, memo)
    return memo[n]

# O(n) vs O(2^n) untuk rekursif biasa
```

**Contoh: Fibonacci dengan Tabulation**
```python
def fib_tab(n):
    if n <= 1:
        return n
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
# O(n) time, O(n) space (bisa dioptimasi jadi O(1))
```

#### C. Masalah Knapsack (0/1 Knapsack)
```python
def knapsack(values, weights, capacity):
    n = len(values)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(1, capacity + 1):
            if weights[i-1] <= w:
                dp[i][w] = max(
                    dp[i-1][w],
                    dp[i-1][w - weights[i-1]] + values[i-1]
                )
            else:
                dp[i][w] = dp[i-1][w]

    return dp[n][capacity]

# Contoh
values = [60, 100, 120]
weights = [10, 20, 30]
capacity = 50
print(knapsack(values, weights, capacity))  # 220
```

#### D. Longest Common Subsequence (LCS)
```python
def lcs(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]

print(lcs("ABCDGH", "AEDFHR"))  # 3 (A, D, H)
```

#### E. Coin Change
```python
def coin_change(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0

    for coin in coins:
        for i in range(coin, amount + 1):
            dp[i] = min(dp[i], dp[i - coin] + 1)

    return dp[amount] if dp[amount] != float('inf') else -1

print(coin_change([1, 2, 5], 11))  # 3 (5+5+1)
```

#### F. Edit Distance (Levenshtein)
```python
def edit_distance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(
                    dp[i-1][j],    # Delete
                    dp[i][j-1],    # Insert
                    dp[i-1][j-1]   # Replace
                )

    return dp[m][n]

print(edit_distance("kitten", "sitting"))  # 3
```

```python
            return self.items.pop()
        raise IndexError("Stack is empty")

        if not self.is_empty():

        return len(self.items) == 0

    def size(self):
        return len(self.items)

# Contoh: Balancing Parentheses
def is_balanced(expression):
    stack = Stack()
    pairs = {')': '(', '}': '{', ']': '['}
    for char in expression:
        if char in '({[':
            stack.push(char)
        elif char in ')}]':
            if stack.is_empty() or stack.pop() != pairs[char]:
                return False
    return stack.is_empty()
```

```python
class LinkedList:

        self.head = None
        self.size = 0

    def append(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            self.size += 1
            return
        current = self.head
        while current.next is not None:
            current = current.next
        current.next = new_node
        self.size += 1

    def prepend(self, data):
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node
        self.size += 1

    def delete(self, data):
        if self.head is None:
            return
        if self.head.data == data:
            self.head = self.head.next
            self.size -= 1
            return
        current = self.head
        while current.next is not None and current.next.data != data:
            current = current.next
        if current.next is not None:
            current.next = current.next.next
            self.size -= 1

    def search(self, data):
        current = self.head
        while current is not None:
            if current.data == data:
                return True
            current = current.next
        return False

    def display(self):
        elements = []
        current = self.head
        while current is not None:
            elements.append(str(current.data))
            current = current.next
        return " -> ".join(elements)

    def reverse(self):
        prev = None
        current = self.head
        while current is not None:
            next_node = current.next
            current.next = prev
            prev = current
            current = next_node
        self.head = prev
```

```python
            self.root = TreeNode(data)
            return
        self._insert(self.root, data)

                node.left = TreeNode(data)
            else:
                self._insert(node.left, data)
        else:

                node.right = TreeNode(data)
            else:

        return self._search(self.root, data)

        if node is None or node.data == data:
            return node
        if data < node.data:
            return self._search(node.left, data)
        return self._search(node.right, data)

        elif data > node.data:

            if node.left is None:

            if node.right is None:
                return node.left

            min_node = self._find_min(node.right)

            node.right = self._delete(node.right, min_node.data)
```

#### B. BFS (Breadth-First Search)
**BFS** = Mencari dengan menjelajahi semua neighbor sebelum melanjutkan ke level berikutnya.

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    result = []

    while queue:
        vertex = queue.popleft()
        result.append(vertex)
        for neighbor in graph[vertex]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return result

# BFS untuk shortest path (unweighted)
def shortest_path(graph, start, target):
    visited = {start}
    queue = deque([(start, [start])])

    while queue:
        vertex, path = queue.popleft()
        if vertex == target:
            return path
        for neighbor in graph[vertex]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None
```

#### C. DFS (Depth-First Search)
**DFS** = Mencari dengan menjelajahi sedalam mungkin sebelum backtrack.

```python
def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    visited.add(start)
    result = [start]
    for neighbor in graph[start]:
        if neighbor not in visited:
            result.extend(dfs(graph, neighbor, visited))
    return result

# Iterative DFS
def dfs_iterative(graph, start):
    visited = set()
    stack = [start]
    result = []

    while stack:
        vertex = stack.pop()
        if vertex not in visited:
            visited.add(vertex)
            result.append(vertex)
            for neighbor in reversed(graph[vertex]):
                if neighbor not in visited:
                    stack.append(neighbor)
    return result
```

#### D. Dijkstra's Algorithm (Shortest Path - Weighted)
```python
import heapq

def dijkstra(graph, start):
    distances = {vertex: float('inf') for vertex in graph}
    distances[start] = 0
    pq = [(0, start)]  # (distance, vertex)

    while pq:
        current_distance, current_vertex = heapq.heappop(pq)

        if current_distance > distances[current_vertex]:
            continue

        for neighbor, weight in graph[current_vertex]:
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(pq, (distance, neighbor))

    return distances

# Graph representation for Dijkstra
graph_with_weight = {
    'A': [('B', 4), ('C', 2)],
    'B': [('A', 4), ('C', 1), ('D', 5)],
    'C': [('A', 2), ('B', 1), ('D', 8)],
    'D': [('B', 5), ('C', 8)]
}

print(dijkstra(graph_with_weight, 'A'))
# {'A': 0, 'B': 3, 'C': 2, 'D': 8}
```

#### E. Floyd-Warshall (All Pairs Shortest Path)
```python
def floyd_warshall(graph):
    n = len(graph)
    dist = [[float('inf')] * n for _ in range(n)]

    for i in range(n):
        for j in range(n):
            if i == j:
                dist[i][j] = 0
            elif graph[i][j] != 0:
                dist[i][j] = graph[i][j]

    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    return dist

graph = [
    [0, 3, 0, 7],
    [3, 0, 1, 0],
    [0, 1, 0, 2],
    [7, 0, 2, 0]
]
print(floyd_warshall(graph))
```

```python
class HashTable:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]

    def _hash(self, key):
        return sum(ord(c) for c in str(key)) % self.size

    def insert(self, key, value):
        index = self._hash(key)
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        self.table[index].append((key, value))

    def get(self, key):
        index = self._hash(key)
        for k, v in self.table[index]:
            if k == key:
                return v
        return None

    def delete(self, key):
        index = self._hash(key)
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index].pop(i)
                return True
        return False

    def display(self):
        for i, bucket in enumerate(self.table):
            print(f"Bucket {i}: {bucket}")
```

```python
import heapq
import datetime

class RegularQueue:
    def __init__(self):
        self.queue = deque()
        self.counter = 1

    def enqueue(self):
        ticket = f"R-{self.counter:04d}"
        self.queue.append(ticket)
        self.counter += 1
        return ticket

    def dequeue(self):
        if self.queue:
            return self.queue.popleft()
        return None

    def size(self):
        return len(self.queue)

class PriorityQueue:
    def __init__(self):
        self.queue = []
        self.counter = 1

    def enqueue(self, priority=0):
        # Lower number = higher priority
        ticket = f"P-{self.counter:04d}"
        heapq.heappush(self.queue, (priority, datetime.datetime.now(), ticket))
        self.counter += 1
        return ticket

    def dequeue(self):
        if self.queue:
            return heapq.heappop(self.queue)[2]
        return None

class CircularQueue:
    def __init__(self, size=10):
        self.size = size
        self.queue = [None] * size
        self.front = 0
        self.rear = 0
        self.count = 0

    def enqueue(self, data):
        if self.is_full():
            print("Queue is full!")
            return False
        self.queue[self.rear] = data
        self.rear = (self.rear + 1) % self.size
        self.count += 1
        return True

    def dequeue(self):
        if self.is_empty():
            return None
        data = self.queue[self.front]
        self.queue[self.front] = None
        self.front = (self.front + 1) % self.size
        self.count -= 1
        return data

    def is_empty(self):
        return self.count == 0

    def is_full(self):
        return self.count == self.size

    def display(self):
        return [self.queue[(self.front + i) % self.size] for i in range(self.count)]

# Main Program

    print(f"Regular: {regular.enqueue()}")
    print(f"Priority (High): {priority.enqueue(0)}")
    print(f"Priority (Medium): {priority.enqueue(1)}")

    # Layani antrian
    print(f"Layani Regular: {regular.dequeue()}")
    print(f"Layani Priority: {priority.dequeue()}")
    print(f"Layani Priority: {priority.dequeue()}")

    # Circular Queue
    for i in range(5):
        circular.enqueue(f"Data-{i+1}")
```

### 8.2 SOLID Principles

**SOLID** adalah 5 prinsip desain OOP yang membuat kode lebih maintainable, scalable, dan fleksibel.

#### A. S - Single Responsibility Principle (SRP)
**Prinsip**: Satu kelas hanya memiliki satu tanggung jawab.

```python
# BAD: Kelas ini melakukan terlalu banyak

        pass

        pass

        # Send via email
        pass
```

#### B. O - Open/Closed Principle (OCP)
**Prinsip**: Kelas harus terbuka untuk ekstensi tetapi tertutup untuk modifikasi.

```python
# BAD: Harus memodifikasi kelas untuk menambah shape baru
class AreaCalculator:
    def calculate(self, shapes):
        total = 0
        for shape in shapes:
            if isinstance(shape, Circle):
                total += shape.radius ** 2 * 3.14
            elif isinstance(shape, Rectangle):
                total += shape.width * shape.height
        return total

# GOOD: Gunakan inheritance
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius ** 2

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

class AreaCalculator:
    def calculate(self, shapes):
        return sum(shape.area() for shape in shapes)
```

#### C. L - Liskov Substitution Principle (LSP)
**Prinsip**: Subclass harus bisa menggantikan parent class tanpa mengubah perilaku program.

```python

# Metaclass untuk singleton
class SingletonMeta(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class SingletonClass(metaclass=SingletonMeta):
    def __init__(self):
        self.value = 0

# Metaclass untuk logging
class LoggingMeta(type):
    def __new__(cls, name, bases, attrs):
        for key, value in attrs.items():
            if callable(value) and not key.startswith("__"):
                attrs[key] = cls.log_method(value)
        return super().__new__(cls, name, bases, attrs)

    @staticmethod
    def log_method(method):
        def wrapper(self, *args, **kwargs):
            print(f"Calling {method.__name__}")
            return method(self, *args, **kwargs)
        return wrapper

class MyClass(metaclass=LoggingMeta):
```

```python
                raise ValueError
        except ValueError:
            messagebox.showwarning("Warning", "Quantity must be integer and price must be number!")
            return

        self.inventory.update_item(item_id, name, category, quantity, price)
        self.clear_entries()
        self.refresh_table()

    def delete_item(self):
        selected = self.tree.selection()
        if not selected:
            messagebox.showwarning("Warning", "Please select an item!")
            return

        item_id = int(self.tree.item(selected[0])['values'][0])
        if messagebox.askyesno("Confirm", "Are you sure you want to delete this item?"):
            self.inventory.delete_item(item_id)
            self.clear_entries()
            self.refresh_table()

    def search_items(self):
        keyword = self.search_entry.get().strip()
        if not keyword:
            self.refresh_table()
            return

        results = self.inventory.search_items(keyword)
        self.display_items(results)

    def show_low_stock(self):
        low_stock = self.inventory.get_low_stock()
        self.display_items(low_stock)

    def display_items(self, items):
        self.tree.delete(*self.tree.get_children())
        for item in items:
            self.tree.insert("", tk.END, values=(item.id, item.name, item.category, item.quantity, f"Rp{item.price:,.2f}"))

    def refresh_table(self):
        self.display_items(self.inventory.items)

    def clear_entries(self):
        self.name_entry.delete(0, tk.END)
        self.category_entry.delete(0, tk.END)
        self.quantity_entry.delete(0, tk.END)
        self.price_entry.delete(0, tk.END)

    def on_select(self, event):
        selected = self.tree.selection()
        if selected:
            values = self.tree.item(selected[0])['values']
            self.name_entry.delete(0, tk.END)
            self.name_entry.insert(0, values[1])
            self.category_entry.delete(0, tk.END)
            self.category_entry.insert(0, values[2])
            self.quantity_entry.delete(0, tk.END)
            self.quantity_entry.insert(0, values[3])
            self.price_entry.delete(0, tk.END)
            self.price_entry.insert(0, values[4].replace("Rp", "").replace(",", ""))

    def export_csv(self):
        filename = filedialog.asksaveasfilename(defaultextension=".csv", filetypes=[("CSV files", "*.csv")])
        if filename:
            self.inventory.export_to_csv(filename)
            messagebox.showinfo("Success", f"Data exported to {filename}")

    def import_csv(self):
        filename = filedialog.askopenfilename(filetypes=[("CSV files", "*.csv")])
        if filename:
            self.inventory.load_from_csv(filename)
            self.refresh_table()
            messagebox.showinfo("Success", f"Data imported from {filename}")

if __name__ == "__main__":
    root = tk.Tk()
    app = InventoryApp(root)
    root.mainloop()
```

### 9.2 Game Loop dan State Management

#### A. Game Loop
Game loop adalah jantung dari setiap game yang berjalan terus menerus untuk:
1. **Update**: Update logika game (AI, physics, score)
2. **Render**: Render frame ke layar
3. **Input**: Proses input dari user

**Pseudocode Game Loop**:
```python
while game_running:
    process_input()
    update()
    render()
```

**Fixed Time Step vs Variable Time Step**:
- Fixed: Update dengan interval tetap (60 fps)
- Variable: Update berdasarkan delta time (elapsed time)

#### B. State Management
Game state mengelola status permainan (menu, gameplay, pause, game over).

```python
class GameState:
    def __init__(self):
        self.current_state = "MENU"

    def switch_state(self, new_state):
        self.current_state = new_state

    def update(self):
        if self.current_state == "MENU":
            self.update_menu()
        elif self.current_state == "GAMEPLAY":
            self.update_gameplay()
        elif self.current_state == "PAUSE":
            self.update_pause()
        elif self.current_state == "GAME_OVER":
            self.update_game_over()
```

#### C. Simple Game Loop dengan Pygame
```python
import pygame
import sys

class Game:
    def __init__(self):
        pygame.init()
        self.screen = pygame.display.set_mode((800, 600))
        pygame.display.set_caption("Simple Game")
        self.clock = pygame.time.Clock()
        self.running = True
        self.player_x = 400
        self.player_y = 300
        self.speed = 5

    def handle_input(self):
        keys = pygame.key.get_pressed()
        if keys[pygame.K_LEFT]:
            self.player_x -= self.speed
        if keys[pygame.K_RIGHT]:
            self.player_x += self.speed
        if keys[pygame.K_UP]:
            self.player_y -= self.speed
        if keys[pygame.K_DOWN]:
            self.player_y += self.speed

    def update(self):
        # Update logic di sini
        # Contoh: boundary
        self.player_x = max(0, min(800 - 50, self.player_x))
        self.player_y = max(0, min(600 - 50, self.player_y))

    def render(self):
        self.screen.fill((0, 0, 0))  # Black background
        pygame.draw.rect(self.screen, (255, 0, 0), (self.player_x, self.player_y, 50, 50))
        pygame.display.flip()

    def run(self):
        while self.running:
            for event in pygame.event.get():
                if event.type == pygame.QUIT:
                    self.running = False

            self.handle_input()
            self.update()
            self.render()
            self.clock.tick(60)  # 60 FPS

        pygame.quit()
        sys.exit()

if __name__ == "__main__":
    game = Game()
    game.run()
```

```csharp
using UnityEngine;

public class PlayerController : MonoBehaviour
{
    // Public variables muncul di Inspector
    public float speed = 5f;
    public float jumpForce = 10f;
    public Transform groundCheck;
    public LayerMask groundLayer;

    private Rigidbody2D rb;
    private bool isGrounded;
    private bool isFacingRight = true;

    void Start()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update()
    {
        // Input handling
        float moveX = Input.GetAxis("Horizontal");
        Move(moveX);

        if (Input.GetButtonDown("Jump") && isGrounded)
        {
            Jump();
        }

        // Flip sprite
        if (moveX > 0 && !isFacingRight) Flip();
        if (moveX < 0 && isFacingRight) Flip();
    }

    void Move(float moveX)
    {
        rb.linearVelocity = new Vector2(moveX * speed, rb.linearVelocity.y);
    }

    void Jump()
    {
        rb.linearVelocity = new Vector2(rb.linearVelocity.x, jumpForce);
    }

    void Flip()
    {
        isFacingRight = !isFacingRight;
        Vector3 scale = transform.localScale;
        scale.x *= -1;
        transform.localScale = scale;
    }

    // Check if grounded using Physics2D.OverlapCircle
    void FixedUpdate()
    {
        isGrounded = Physics2D.OverlapCircle(groundCheck.position, 0.2f, groundLayer);
    }
}
```

```gdscript
extends Area2D

# Variables
@export var speed = 300
@export var health = 100
@export var damage = 20

var velocity = Vector2.ZERO
var facing_direction = 1

func _ready():
    # Called when node added to scene
    print("Player ready!")
    position = Vector2(400, 300)

func _process(delta):
    # Called every frame
    handle_input(delta)
    movement(delta)
    animate()

func _physics_process(delta):
    # Called for physics (use delta for physics)
    pass

func handle_input(delta):
    velocity = Vector2.ZERO
    if Input.is_action_pressed("ui_right"):
        velocity.x += 1
    if Input.is_action_pressed("ui_left"):
        velocity.x -= 1
    if Input.is_action_pressed("ui_down"):
        velocity.y += 1
    if Input.is_action_pressed("ui_up"):
        velocity.y -= 1

    # Normalize for diagonal speed
    if velocity.length() > 0:
        velocity = velocity.normalized() * speed

func movement(delta):
    position += velocity * delta

func animate():
    if velocity.x != 0:
        # Flip sprite
        $Sprite2D.flip_h = velocity.x < 0

func take_damage(amount):
    health -= amount
    if health <= 0:
        die()

func die():
    queue_free()

func _on_body_entered(body):
    if body.is_in_group("enemies"):
        take_damage(damage)
        body.queue_free()
```
