# BAB 1: PEMROGRAMAN TERSTRUKTUR DENGAN JAVA

## A. Pengantar Pemrograman dengan Java

Java adalah bahasa pemrograman yang populer untuk pengembangan aplikasi desktop, web, dan mobile. NetBeans IDE adalah salah satu lingkungan pengembangan terbaik untuk Java, menyediakan alat visual untuk membangun antarmuka pengguna (GUI) dan mengelola proyek .

### 1.1 Instalasi dan Persiapan

**Langkah-langkah memulai proyek Java di NetBeans :**

1. Buka NetBeans IDE
2. Pilih **File → New Project**
3. Pada kategori, pilih **Java with Ant** atau **JavaFX**
4. Pilih jenis proyek yang diinginkan (Java Application atau JavaFX Application)
5. Beri nama proyek dan tentukan lokasi penyimpanan
6. Klik **Finish**

### 1.2 Struktur Dasar Program Java

```java
/*
 * PROGRAM PERTAMA DI JAVA
 * Nama File: HelloWorld.java
 */

// 1. PAKET (Package) - Mengelompokkan kelas-kelas terkait
package com.contoh.program;

// 2. IMPORT - Mengimpor kelas dari paket lain
import java.util.Scanner;

// 3. DEKLARASI KELAS - Setiap program Java dimulai dengan kelas
public class HelloWorld {
    
    // 4. METHOD MAIN - Titik awal eksekusi program
    public static void main(String[] args) {
        // 5. KODE PROGRAM - Instruksi yang akan dijalankan
        System.out.println("Hello, World!");
        
        // 6. VARIABEL - Menyimpan data
        String nama = "Budi";
        int umur = 17;
        
        // 7. OUTPUT - Menampilkan hasil
        System.out.println("Nama: " + nama);
        System.out.println("Umur: " + umur);
    }
}
```

**Penjelasan Struktur:**

| Komponen | Penjelasan |

## B. Pemrograman Terstruktur di Java

### 2.1 Konsep Pemrograman Terstruktur

**Pemrograman terstruktur** adalah paradigma pemrograman yang menggunakan fungsi-fungsi terpisah untuk mengorganisir kode. Program dijalankan secara berurutan dari atas ke bawah (top-down) .

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│  CIRI-CIRI PEMROGRAMAN TERSTRUKTUR                                                  │
├─────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
│  1. PROSEDURAL                                                                      │
│     └── Program dijalankan secara berurutan (top-down)                             │
│                                                                                     │
│  2. FUNGSI TERPISAH                                                                │
│     └── Kode dibagi menjadi fungsi-fungsi yang spesifik                           │
│                                                                                     │
│  3. DATA DAN FUNGSI TERPISAH                                                       │
│     └── Data disimpan terpisah dari fungsi yang memprosesnya                       │
│                                                                                     │
│  4. KONTROL ALUR TERSTRUKTUR                                                       │
│     └── Menggunakan percabangan (if-else) dan perulangan (for, while)             │
│                                                                                     │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 Contoh Pemrograman Terstruktur dengan Java

```java
/*
 * CONTOH PEMROGRAMAN TERSTRUKTUR
 * Program menghitung luas persegi panjang
 * Nama File: LuasPersegiPanjang.java
 */

package com.contoh.struktur;

import java.util.Scanner;

public class LuasPersegiPanjang {
    
    // FUNGSI 1: Input panjang
    public static double inputPanjang() {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Masukkan panjang: ");
        return scanner.nextDouble();
    }
    
    // FUNGSI 2: Input lebar
    public static double inputLebar() {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Masukkan lebar: ");
        return scanner.nextDouble();
    }
    
    // FUNGSI 3: Menghitung luas
    public static double hitungLuas(double panjang, double lebar) {
        return panjang * lebar;
    }
    
    // FUNGSI 4: Menampilkan hasil
    public static void tampilkanHasil(double luas) {
        System.out.println("Luas persegi panjang: " + luas);
    }
    
    // PROGRAM UTAMA - alur eksekusi berurutan
    public static void main(String[] args) {
        // Langkah 1: Input data
        double panjang = inputPanjang();
        double lebar = inputLebar();
        
        // Langkah 2: Proses data
        double luas = hitungLuas(panjang, lebar);
        
        // Langkah 3: Output hasil
        tampilkanHasil(luas);
    }
}
```

**Penjelasan Kode:**
1. Program terdiri dari fungsi-fungsi terpisah (`inputPanjang()`, `inputLebar()`, `hitungLuas()`, `tampilkanHasil()`)
2. Setiap fungsi memiliki tugas spesifik (Single Responsibility)
3. Data (`panjang` dan `lebar`) dipisahkan dari fungsi
4. Alur eksekusi berjalan dari `main()` → memanggil fungsi-fungsi secara berurutan

### 2.3 Kontrol Alur dalam Pemrograman Terstruktur

```java
/*
 * CONTOH KONTROL ALUR
 * Percabangan dan Perulangan dalam Java
 */

package com.contoh.struktur;

public class KontrolAlur {
    
    public static void main(String[] args) {
        
        // 1. PERCABANGAN (Conditional)
        // IF-ELSE
        int nilai = 85;
        
        if (nilai >= 90) {
            System.out.println("Grade: A");
        } else if (nilai >= 75) {
            System.out.println("Grade: B");
        } else if (nilai >= 60) {
            System.out.println("Grade: C");
        } else {
            System.out.println("Grade: D");
        }
        
        // SWITCH-CASE
        int hari = 3;
        switch (hari) {
            case 1:
                System.out.println("Senin");
                break;
            case 2:
                System.out.println("Selasa");
                break;
            case 3:
                System.out.println("Rabu");
                break;
            default:
                System.out.println("Hari tidak valid");
                break;
        }
        
        // 2. PERULANGAN (Looping)
        // FOR LOOP - diketahui jumlah perulangan
        for (int i = 1; i <= 5; i++) {
            System.out.println("Perulangan ke-" + i);
        }
        
        // WHILE LOOP - kondisi di cek di awal
        int j = 1;
        while (j <= 5) {
            System.out.println("While ke-" + j);
            j++;
        }
        
        // DO-WHILE LOOP - dieksekusi minimal sekali
        int k = 1;
        do {
            System.out.println("Do-While ke-" + k);
            k++;
        } while (k <= 5);
    }
}
```

## C. Metode (Method) dalam Pemrograman Terstruktur

### 3.1 Pengertian Method

Method atau fungsi adalah blok kode yang dapat dipanggil berulang kali. Method membantu mengorganisir kode menjadi bagian-bagian yang lebih kecil dan terkelola .

```java
/*
 * CONTOH METHOD
 * Nama File: MetodeContoh.java
 */

package com.contoh.struktur;

public class MetodeContoh {
    
    // METHOD TANPA RETURN (void) - Hanya menjalankan aksi
    public static void sapa() {
        System.out.println("Halo, selamat datang!");
    }
    
    // METHOD DENGAN PARAMETER
    public static void sapaNama(String nama) {
        System.out.println("Halo, " + nama + "!");
    }
    
    // METHOD DENGAN RETURN (mengembalikan nilai)
    public static int tambah(int a, int b) {
        return a + b;
    }
    
    // METHOD DENGAN RETURN DAN MULTIPLE PARAMETER
    public static double hitungRataRata(int[] nilai) {
        int total = 0;
        for (int n : nilai) {
            total += n;
        }
        return (double) total / nilai.length;
    }
    
    // PROGRAM UTAMA
    public static void main(String[] args) {
        // Memanggil method tanpa parameter
        sapa();
        
        // Memanggil method dengan parameter
        sapaNama("Budi");
        
        // Memanggil method dengan return
        int hasil = tambah(5, 3);
        System.out.println("5 + 3 = " + hasil);
        
        // Memanggil method dengan array
        int[] nilaiMahasiswa = {80, 85, 90, 75, 95};
        double rata = hitungRataRata(nilaiMahasiswa);
        System.out.println("Rata-rata nilai: " + rata);
    }
}
```

### 3.2 Overloading Method

Overloading adalah kemampuan untuk memiliki beberapa method dengan nama yang sama tetapi parameter yang berbeda .

```java
/*
 * CONTOH OVERLOADING METHOD
 * Method dengan nama sama tetapi parameter berbeda
 */

package com.contoh.struktur;

public class OverloadingContoh {
    
    // Versi 1: Menghitung luas persegi
    public static double hitungLuas(double sisi) {
        return sisi * sisi;
    }
    
    // Versi 2: Menghitung luas persegi panjang
    public static double hitungLuas(double panjang, double lebar) {
        return panjang * lebar;
    }
    
    // Versi 3: Menghitung luas lingkaran
    public static double hitungLuas(double jariJari, boolean lingkaran) {
        return 3.14 * jariJari * jariJari;
    }
    
    public static void main(String[] args) {
        System.out.println("Luas persegi (5): " + hitungLuas(5));
        System.out.println("Luas persegi panjang (4, 6): " + hitungLuas(4, 6));
        System.out.println("Luas lingkaran (7): " + hitungLuas(7, true));
    }
}
```

### 1.2 Kelas dan Objek di Java

```java
/*
 * CONTOH KELAS DAN OBJEK
 * Nama File: Mobil.java
 */

package com.contoh.oop;

// 1. MENDEFINISIKAN KELAS (Blueprint/Cetakan)
public class Mobil {
    
    // 2. ATRIBUT / PROPERTI (Data/Keadaan objek)
    private String merk;
    private String warna;
    private int kecepatan;
    private int roda;
    
    // 3. KONSTRUKTOR (Method khusus untuk membuat objek)
    // Konstruktor default
    public Mobil() {
        this.merk = "Unknown";
        this.warna = "Putih";
        this.kecepatan = 0;
        this.roda = 4;
    }
    
    // Konstruktor dengan parameter
    public Mobil(String merk, String warna, int roda) {
        this.merk = merk;
        this.warna = warna;
        this.kecepatan = 0;
        this.roda = roda;
    }
    
    // 4. GETTER dan SETTER (Encapsulation)
    public String getMerk() {
        return merk;
    }
    
    public void setMerk(String merk) {
        this.merk = merk;
    }
    
    public String getWarna() {
        return warna;
    }
    
    public void setWarna(String warna) {
        this.warna = warna;
    }
    
    public int getKecepatan() {
        return kecepatan;
    }
    
    // 5. METODE / PERILAKU (Behaviour)
    public void jalan() {
        kecepatan = 20;
        System.out.println(merk + " sedang berjalan dengan kecepatan " + kecepatan + " km/jam");
    }
    
    public void tambahKecepatan(int increment) {
        kecepatan += increment;
        System.out.println(merk + " menambah kecepatan menjadi " + kecepatan + " km/jam");
    }
    
    public void rem() {
        kecepatan = 0;
        System.out.println(merk + " berhenti");
    }
    
    public void tampilkanInfo() {
        System.out.println("===== INFO MOBIL =====");
        System.out.println("Merk: " + merk);
        System.out.println("Warna: " + warna);
        System.out.println("Kecepatan: " + kecepatan + " km/jam");
        System.out.println("Roda: " + roda);
        System.out.println("======================");
    }
}
```


## B. Enkapsulasi (Encapsulation)

### 2.1 Pengertian Enkapsulasi

Enkapsulasi adalah konsep menyembunyikan detail implementasi dan melindungi data dari akses langsung dari luar kelas. Data dibuat private dan diakses melalui method getter dan setter .

```java
/*
 * CONTOH ENKAPSULASI
 * Nama File: BankAccount.java
 */

package com.contoh.oop;

public class BankAccount {
    
    // ATRIBUT PRIVATE - Tidak bisa diakses langsung dari luar
    private String namaPemilik;
    private String nomorRekening;
    private double saldo;
    
    // KONSTRUKTOR
    public BankAccount(String namaPemilik, String nomorRekening) {
        this.namaPemilik = namaPemilik;
        this.nomorRekening = nomorRekening;
        this.saldo = 0.0;
    }
    
    // GETTER - Mengambil nilai atribut (Read Only)
    public String getNamaPemilik() {
        return namaPemilik;
    }
    
    public String getNomorRekening() {
        return nomorRekening;
    }
    
    public double getSaldo() {
        return saldo;
    }
    
    // SETTER - Mengubah nilai dengan validasi
    public void setNamaPemilik(String namaPemilik) {
        if (namaPemilik != null && !namaPemilik.isEmpty()) {
            this.namaPemilik = namaPemilik;
        } else {
            System.out.println("Nama tidak boleh kosong!");
        }
    }
    
    // METODE BISNIS - Operasi pada data
    public void deposit(double jumlah) {
        if (jumlah > 0) {
            saldo += jumlah;
            System.out.println("Deposit Rp" + jumlah + " berhasil");
            System.out.println("Saldo saat ini: Rp" + saldo);
        } else {
            System.out.println("Jumlah deposit harus positif!");
        }
    }
    
    public void withdraw(double jumlah) {
        if (jumlah > 0) {
            if (jumlah <= saldo) {
                saldo -= jumlah;
                System.out.println("Penarikan Rp" + jumlah + " berhasil");
                System.out.println("Saldo saat ini: Rp" + saldo);
            } else {
                System.out.println("Saldo tidak mencukupi!");
            }
        } else {
            System.out.println("Jumlah penarikan harus positif!");
        }
    }
    
    public void tampilkanInfo() {
        System.out.println("===== INFO REKENING =====");
        System.out.println("Nama: " + namaPemilik);
        System.out.println("No. Rekening: " + nomorRekening);
        System.out.println("Saldo: Rp" + saldo);
        System.out.println("========================");
    }
}
```

**Mengapa Enkapsulasi Penting?**

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│  MANFAAT ENKAPSULASI                                                                │
├─────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
```

## C. Inheritance (Pewarisan)

### 3.1 Pengertian Inheritance

Inheritance memungkinkan sebuah kelas mewarisi atribut dan method dari kelas lain. Kelas yang mewarisi disebut **subclass** (kelas anak), dan kelas yang diwarisi disebut **superclass** (kelas induk) .

```java
/*
 * CONTOH INHERITANCE
 * Nama File: Kendaraan.java (Superclass / Kelas Induk)
 */

package com.contoh.oop;

// KELAS INDUK (Superclass)
public class Kendaraan {
    
    // Atribut yang akan diwarisi
    protected String merk;
    protected String warna;
    protected int kecepatan;
    
    // Konstruktor
    public Kendaraan(String merk, String warna) {
        this.merk = merk;
        this.warna = warna;
        this.kecepatan = 0;
    }
    
    // Method yang akan diwarisi
    public void jalan() {
        kecepatan = 20;
        System.out.println(merk + " sedang berjalan dengan kecepatan " + kecepatan + " km/jam");
    }
    
    public void rem() {
        kecepatan = 0;
        System.out.println(merk + " berhenti");
    }
    
    public void tampilkanInfo() {
        System.out.println("Merk: " + merk);
        System.out.println("Warna: " + warna);
        System.out.println("Kecepatan: " + kecepatan + " km/jam");
    }
}
```

```java
/*
 * KELAS ANAK (Subclass) - Mobil
 * Nama File: Mobil.java
 */

package com.contoh.oop;

// EXTENDS = Mewarisi dari Kendaraan
public class Mobil extends Kendaraan {
    
    // Atribut tambahan khusus mobil
    private int jumlahPintu;
    private String tipeMesin;
    
    // Konstruktor
    public Mobil(String merk, String warna, int jumlahPintu, String tipeMesin) {
        // SUPER = Memanggil konstruktor kelas induk
        super(merk, warna);
        this.jumlahPintu = jumlahPintu;
        this.tipeMesin = tipeMesin;
    }
    
    // Method tambahan khusus mobil
    public void bukaPintu() {
        System.out.println("Membuka " + jumlahPintu + " pintu " + merk);
    }
    
    // OVERRIDE = Mengganti method dari kelas induk
    @Override
    public void tampilkanInfo() {
        super.tampilkanInfo();  // Memanggil method induk
        System.out.println("Jumlah Pintu: " + jumlahPintu);
        System.out.println("Tipe Mesin: " + tipeMesin);
    }
}
```

## D. Polimorfisme (Polymorphism)

### 4.1 Pengertian Polimorfisme

Polimorfisme adalah kemampuan suatu objek untuk memiliki banyak bentuk. Method yang sama dapat memiliki perilaku yang berbeda pada kelas yang berbeda .

```java
/*
 * CONTOH POLIMORFISME
 * Nama File: PolimorfismeContoh.java
 */

package com.contoh.oop;

// KELAS ABSTRAK - Tidak bisa dibuat objek langsung
abstract class Hewan {
    protected String nama;
    
    public Hewan(String nama) {
        this.nama = nama;
    }
    
    // METHOD ABSTRAK - Harus diimplementasikan oleh kelas anak
    public abstract void suara();
    
    public void makan() {
        System.out.println(nama + " sedang makan");
    }
}

// KELAS ANAK 1
class Kucing extends Hewan {
    public Kucing(String nama) {
        super(nama);
    }
    
    @Override
    public void suara() {
        System.out.println(nama + " bersuara: Meong! Meong!");
    }
    
    public void mengejarTikus() {
        System.out.println(nama + " mengejar tikus");
    }
}

// KELAS ANAK 2
class Anjing extends Hewan {
    public Anjing(String nama) {
        super(nama);
    }
    
    @Override
    public void suara() {
        System.out.println(nama + " bersuara: Guk! Guk!");
    }
    
    public void menjagaRumah() {
        System.out.println(nama + " menjaga rumah");
    }
}

// KELAS ANAK 3
class Burung extends Hewan {
    public Burung(String nama) {
        super(nama);
    }
    
    @Override
    public void suara() {
        System.out.println(nama + " bersuara: Kicau! Kicau!");
    }
    
    public void terbang() {
        System.out.println(nama + " sedang terbang");
    }
}

// PROGRAM UTAMA
public class PolimorfismeContoh {
    
    public static void main(String[] args) {
        
        // POLIMORFISME: Referensi Hewan bisa menunjuk ke objek anak
        Hewan hewan1 = new Kucing("Kitty");
        Hewan hewan2 = new Anjing("Doggy");
        Hewan hewan3 = new Burung("Tweety");
        
        // Memanggil method yang sama - hasil berbeda (Polimorfisme)
        System.out.println("=== POLIMORFISME ===");
        hewan1.suara();  // Kitty bersuara: Meong! Meong!
        hewan2.suara();  // Doggy bersuara: Guk! Guk!
        hewan3.suara();  // Tweety bersuara: Kicau! Kicau!
        
        // Method yang sama di semua kelas
        hewan1.makan();
        hewan2.makan();
        hewan3.makan();
        
        System.out.println("\n=== DOWNCASTING ===");
        // DOWNCASTING - Mengubah tipe referensi untuk akses method spesifik
        if (hewan1 instanceof Kucing) {
            Kucing kucing = (Kucing) hewan1;
            kucing.mengejarTikus();
        }
        
        if (hewan2 instanceof Anjing) {
            Anjing anjing = (Anjing) hewan2;
            anjing.menjagaRumah();
        }
        
        if (hewan3 instanceof Burung) {
            Burung burung = (Burung) hewan3;
            burung.terbang();
        }
    }
}
```

### 4.2 Overriding vs Overloading

```

│  PERBEDAAN OVERRIDING DAN OVERLOADING                                              │
├─────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
│  OVERRIDING (Menimpa)                                                              │
│  ├── Terjadi pada kelas yang berbeda (parent-child)                               │

│                                                                                     │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

## E. Abstraksi (Abstraction)

### 5.1 Pengertian Abstraksi

Abstraksi adalah konsep menyembunyikan detail implementasi dan hanya menampilkan fungsionalitas yang penting. Di Java, abstraksi diimplementasikan menggunakan **abstract class** dan **interface** .

### 5.2 Abstract Class

```java
/*
 * CONTOH ABSTRACT CLASS
 * Nama File: Bentuk.java
 */

package com.contoh.oop;

// ABSTRACT CLASS - Tidak bisa dibuat objek langsung
public abstract class Bentuk {
    
    // Atribut
    protected String nama;
    
    // Konstruktor
    public Bentuk(String nama) {
        this.nama = nama;
    }
    
    // METHOD ABSTRAK - Harus diimplementasikan oleh kelas anak
    public abstract double hitungLuas();
    public abstract double hitungKeliling();
    
    // METHOD CONCRETE - Bisa langsung digunakan
    public void tampilkanInfo() {
        System.out.println("Nama: " + nama);
        System.out.println("Luas: " + hitungLuas());
        System.out.println("Keliling: " + hitungKeliling());
    }
}

// KELAS ANAK - Mengimplementasikan abstract class
class Persegi extends Bentuk {
    private double sisi;
    
    public Persegi(String nama, double sisi) {
        super(nama);
        this.sisi = sisi;
    }
    
    @Override
    public double hitungLuas() {
        return sisi * sisi;
    }
    
    @Override
    public double hitungKeliling() {
        return 4 * sisi;
    }
}

class Lingkaran extends Bentuk {
    private double jariJari;
    
    public Lingkaran(String nama, double jariJari) {
        super(nama);
        this.jariJari = jariJari;
    }
    
    @Override
    public double hitungLuas() {
        return Math.PI * jariJari * jariJari;
    }
    
    @Override
    public double hitungKeliling() {
        return 2 * Math.PI * jariJari;
    }
}
```

```java
/*
```

```java
 * Nama File: PemesananMakanan.java

package com.contoh.workflow;

import java.util.ArrayList;
import java.util.Scanner;

// KELAS PRODUK
class Produk {
    private int id;
    private String nama;
    private double harga;
    
    public Produk(int id, String nama, double harga) {
        this.id = id;
        this.nama = nama;
        this.harga = harga;
    }
    
    public int getId() { return id; }
    public String getNama() { return nama; }
    public double getHarga() { return harga; }
    
    @Override
    public String toString() {
        return id + ". " + nama + " - Rp" + harga;
    }
}

// KELAS ITEM KERANJANG
class ItemKeranjang {
    private Produk produk;
    private int jumlah;
    
    public ItemKeranjang(Produk produk, int jumlah) {
        this.produk = produk;
        this.jumlah = jumlah;
    }
    
    public Produk getProduk() { return produk; }
    public int getJumlah() { return jumlah; }
    public double getSubTotal() { return produk.getHarga() * jumlah; }
    
    public void tambahJumlah() { jumlah++; }
    public void kurangiJumlah() { if (jumlah > 1) jumlah--; }
}

// KELAS KERANJANG
class Keranjang {
    private ArrayList<ItemKeranjang> items = new ArrayList<>();
    
    public void tambahItem(Produk produk) {
        for (ItemKeranjang item : items) {
            if (item.getProduk().getId() == produk.getId()) {
                item.tambahJumlah();
                return;
            }
        }
        items.add(new ItemKeranjang(produk, 1));
    }
    
    public void hapusItem(int id) {
        items.removeIf(item -> item.getProduk().getId() == id);
    }
    
    public ArrayList<ItemKeranjang> getItems() { return items; }
    
    public double getTotal() {
        double total = 0;
        for (ItemKeranjang item : items) {
            total += item.getSubTotal();
        }
        return total;
    }
    
    public void tampilkanKeranjang() {
        if (items.isEmpty()) {
            System.out.println("Keranjang kosong!");
            return;
        }
        System.out.println("\n===== KERANJANG BELANJA =====");
        for (ItemKeranjang item : items) {
            System.out.println(item.getProduk().getNama() + " x" + item.getJumlah() + 
                             " = Rp" + item.getSubTotal());
        }
        System.out.println("Total: Rp" + getTotal());
        System.out.println("==============================");
    }
}

// PROGRAM UTAMA
public class PemesananMakanan {
    
    private static Scanner scanner = new Scanner(System.in);
    private static ArrayList<Produk> daftarProduk = new ArrayList<>();
    private static Keranjang keranjang = new Keranjang();
    
    // Inisialisasi data produk
    static {
        daftarProduk.add(new Produk(1, "Nasi Goreng", 25000));
        daftarProduk.add(new Produk(2, "Mie Goreng", 20000));
        daftarProduk.add(new Produk(3, "Ayam Geprek", 30000));
        daftarProduk.add(new Produk(4, "Es Teh", 5000));
        daftarProduk.add(new Produk(5, "Jus Jeruk", 10000));
    }
    
    // TAMPILKAN MENU
    public static void tampilkanMenu() {
        System.out.println("\n===== MENU MAKANAN =====");
        for (Produk p : daftarProduk) {
            System.out.println(p);
        }
        System.out.println("========================");
    }
    
    // ALUR KERJA: Pilih Produk
    public static void pilihProduk() {
        System.out.print("Pilih ID produk: ");
        int id = scanner.nextInt();
        
        for (Produk p : daftarProduk) {
            if (p.getId() == id) {
                keranjang.tambahItem(p);
                System.out.println(p.getNama() + " ditambahkan ke keranjang!");
                return;
            }
        }
        System.out.println("Produk tidak ditemukan!");
    }
    
    // ALUR KERJA: Checkout
    public static void checkout() {
        if (keranjang.getItems().isEmpty()) {
            System.out.println("Keranjang kosong! Silakan belanja dulu.");
            return;
        }
        
        keranjang.tampilkanKeranjang();
        System.out.println("\n1. Lanjutkan ke pembayaran");
        System.out.println("2. Kembali");
        System.out.print("Pilih: ");
        int pilihan = scanner.nextInt();
        
        if (pilihan == 1) {
            prosesPembayaran();
        }
    }
    
    // ALUR KERJA: Proses Pembayaran
    public static void prosesPembayaran() {
        System.out.println("\n===== PEMBAYARAN =====");
        System.out.println("Total belanja: Rp" + keranjang.getTotal());
        System.out.print("Bayar dengan tunai: Rp");
        double bayar = scanner.nextDouble();
        
        if (bayar >= keranjang.getTotal()) {
            double kembalian = bayar - keranjang.getTotal();
            System.out.println("Pembayaran berhasil!");
            System.out.println("Kembalian: Rp" + kembalian);
            
            // Reset keranjang setelah pembayaran
            keranjang.getItems().clear();
            System.out.println("Terima kasih telah berbelanja!");
        } else {
            System.out.println("Uang tidak cukup!");
            System.out.println("Kurang: Rp" + (keranjang.getTotal() - bayar));
        }
    }
    
    // PROGRAM UTAMA
    public static void main(String[] args) {
        boolean running = true;
        
        while (running) {
            System.out.println("\n===== SISTEM PEMESANAN MAKANAN =====");
            System.out.println("1. Lihat Menu");
            System.out.println("2. Tambah ke Keranjang");
            System.out.println("3. Lihat Keranjang");
            System.out.println("4. Checkout");
            System.out.println("5. Keluar");
            System.out.print("Pilih: ");
            
            int pilihan = scanner.nextInt();
            
            switch (pilihan) {
                case 1:
                    tampilkanMenu();
                    break;
                case 2:
                    tampilkanMenu();
                    pilihProduk();
                    break;
                case 3:
                    keranjang.tampilkanKeranjang();
                    break;
                case 4:
                    checkout();
                    break;
                case 5:
                    running = false;
                    System.out.println("Terima kasih!");
                    break;
                default:
                    System.out.println("Pilihan tidak valid!");
            }
        }
        scanner.close();
    }
}
```

```java
/*
 * CONTOH RELASI ANTAR KELAS - SISTEM PERPUSTAKAAN
 * Nama File: RelasiContoh.java
 */

package com.contoh.relasi;

import java.util.ArrayList;

// 1. RELASI ONE-TO-MANY: Satu Anggota bisa meminjam banyak Buku
class Anggota {
    private int idAnggota;
    private String nama;
    private String alamat;
    private ArrayList<Buku> daftarPinjaman = new ArrayList<>();
    
    public Anggota(int idAnggota, String nama, String alamat) {
        this.idAnggota = idAnggota;
        this.nama = nama;
        this.alamat = alamat;
    }
    
    // Method untuk meminjam buku (menambah ke daftar pinjaman)
    public void pinjamBuku(Buku buku) {
        if (buku.isTersedia()) {
            buku.setTersedia(false);
            daftarPinjaman.add(buku);
            System.out.println(nama + " meminjam buku: " + buku.getJudul());
        } else {
            System.out.println("Buku " + buku.getJudul() + " sedang dipinjam!");
        }
    }
    
    // Method untuk mengembalikan buku
    public void kembalikanBuku(Buku buku) {
        if (daftarPinjaman.remove(buku)) {
            buku.setTersedia(true);
            System.out.println(nama + " mengembalikan buku: " + buku.getJudul());
        } else {
            System.out.println("Buku tidak ditemukan dalam daftar pinjaman!");
        }
    }
    
    public void tampilkanPinjaman() {
        System.out.println("\nDaftar pinjaman " + nama + ":");
        if (daftarPinjaman.isEmpty()) {
            System.out.println("Tidak ada buku yang dipinjam");
        } else {
            for (Buku b : daftarPinjaman) {
                System.out.println("- " + b.getJudul());
            }
        }
    }
    
    // Getter
    public String getNama() { return nama; }
}

// 2. RELASI MANY-TO-MANY: Buku dan Penulis
class Penulis {
    private int idPenulis;
    private String nama;
    private ArrayList<Buku> daftarBuku = new ArrayList<>();
    
    public Penulis(int idPenulis, String nama) {
        this.idPenulis = idPenulis;
        this.nama = nama;
    }
    
    public void tambahBuku(Buku buku) {
        daftarBuku.add(buku);
        buku.tambahPenulis(this);
    }
    
    public void tampilkanBuku() {
        System.out.println("Buku karya " + nama + ":");
        for (Buku b : daftarBuku) {
            System.out.println("- " + b.getJudul());
        }
    }
    
    public String getNama() { return nama; }
}

class Buku {
    private int idBuku;
    private String judul;
    private String isbn;
    private boolean tersedia;
    private ArrayList<Penulis> daftarPenulis = new ArrayList<>();
    
    public Buku(int idBuku, String judul, String isbn) {
        this.idBuku = idBuku;
        this.judul = judul;
        this.isbn = isbn;
        this.tersedia = true;
    }
    
    public void tambahPenulis(Penulis penulis) {
        if (!daftarPenulis.contains(penulis)) {
            daftarPenulis.add(penulis);
        }
    }
    
    public void tampilkanPenulis() {
        System.out.print("Penulis " + judul + ": ");
        for (Penulis p : daftarPenulis) {
            System.out.print(p.getNama() + " ");
        }
        System.out.println();
    }
    
    // Getter dan Setter
    public String getJudul() { return judul; }
    public boolean isTersedia() { return tersedia; }
    public void setTersedia(boolean tersedia) { this.tersedia = tersedia; }
}

// PROGRAM UTAMA
public class RelasiContoh {
    
    public static void main(String[] args) {
        
        // Membuat objek Penulis
        Penulis penulis1 = new Penulis(1, "Andrea Hirata");
        Penulis penulis2 = new Penulis(2, "Pramoedya Ananta Toer");
        
        // Membuat objek Buku
        Buku buku1 = new Buku(101, "Laskar Pelangi", "978-979-3062-92-9");
        Buku buku2 = new Buku(102, "Sang Pemimpi", "978-979-3062-98-1");
        Buku buku3 = new Buku(103, "Bumi Manusia", "978-979-3062-66-0");
        
        // Relasi MANY-TO-MANY: Buku - Penulis
        penulis1.tambahBuku(buku1);
        penulis1.tambahBuku(buku2);
        penulis2.tambahBuku(buku3);
```

```java
/*
 * CONTOH INTERAKSI ANTAR OBJEK - SISTEM KASIR
 * Nama File: InteraksiObjek.java

package com.contoh.interaksi;

import java.util.ArrayList;

// KELAS PRODUK
class Produk {
    private int id;
    private String nama;
    private double harga;
    private int stok;
    
    public Produk(int id, String nama, double harga, int stok) {
        this.id = id;
        this.nama = nama;
        this.harga = harga;
        this.stok = stok;
    }
    
    public boolean kurangiStok(int jumlah) {
        if (stok >= jumlah) {
            stok -= jumlah;
            return true;
        }
        return false;
    }
    
    public void tambahStok(int jumlah) {
        stok += jumlah;
    }
    
    // Getter
    public int getId() { return id; }
    public String getNama() { return nama; }
    public double getHarga() { return harga; }
    public int getStok() { return stok; }
    
    @Override
    public String toString() {
        return id + ". " + nama + " - Rp" + harga + " (Stok: " + stok + ")";
    }
}

// KELAS TRANSAKSI
class Transaksi {
    private int idTransaksi;
    private ArrayList<ItemTransaksi> items = new ArrayList<>();
    private double total;
    private boolean selesai;
    
    public Transaksi(int idTransaksi) {
        this.idTransaksi = idTransaksi;
        this.total = 0;
        this.selesai = false;
    }
    
    // Menambahkan item ke transaksi
    public boolean tambahItem(Produk produk, int jumlah) {
        if (produk.kurangiStok(jumlah)) {
            items.add(new ItemTransaksi(produk, jumlah));
            total += produk.getHarga() * jumlah;
            System.out.println(jumlah + " " + produk.getNama() + " ditambahkan ke transaksi");
            return true;
        } else {
            System.out.println("Stok " + produk.getNama() + " tidak mencukupi!");
            return false;
        }
    }
    
    public double getTotal() { return total; }
    public boolean isSelesai() { return selesai; }
    public void setSelesai() { this.selesai = true; }
    
    public void tampilkanStruk() {
        System.out.println("\n===== STRUK BELANJA =====");
        System.out.println("Transaksi #" + idTransaksi);
        for (ItemTransaksi item : items) {
            System.out.println(item.getProduk().getNama() + " x" + item.getJumlah() + 
                             " = Rp" + item.getSubTotal());
        }
        System.out.println("Total: Rp" + total);
        System.out.println("Status: " + (selesai ? "Selesai" : "Belum selesai"));
        System.out.println("========================");
    }
}

// KELAS ITEM TRANSAKSI
class ItemTransaksi {
    private Produk produk;
    private int jumlah;
    
    public ItemTransaksi(Produk produk, int jumlah) {
        this.produk = produk;
        this.jumlah = jumlah;
    }
    
    public Produk getProduk() { return produk; }
    public int getJumlah() { return jumlah; }
    public double getSubTotal() { return produk.getHarga() * jumlah; }
}

// KELAS KASIR (Mengelola interaksi antar objek)
class Kasir {
    private String namaKasir;
    private ArrayList<Transaksi> daftarTransaksi = new ArrayList<>();
    private int counterTransaksi = 1;
    
    public Kasir(String namaKasir) {
        this.namaKasir = namaKasir;
    }
    
    // Membuat transaksi baru
    public Transaksi buatTransaksi() {
        Transaksi transaksi = new Transaksi(counterTransaksi++);
        daftarTransaksi.add(transaksi);
        System.out.println("Transaksi #" + transaksi.getIdTransaksi() + " dibuat");
        return transaksi;
    }
    
    // Menyelesaikan transaksi
    public void selesaikanTransaksi(Transaksi transaksi) {
        if (!transaksi.isSelesai()) {
            transaksi.setSelesai();
            transaksi.tampilkanStruk();
            System.out.println("Transaksi selesai. Total: Rp" + transaksi.getTotal());
        } else {
            System.out.println("Transaksi sudah selesai!");
        }
    }
    
    public void tampilkanSemuaTransaksi() {
        System.out.println("\n===== SEMUA TRANSAKSI =====");
        for (Transaksi t : daftarTransaksi) {
            System.out.println("Transaksi #" + t.getIdTransaksi() + 
                             " - Total: Rp" + t.getTotal() + 
                             " - Status: " + (t.isSelesai() ? "Selesai" : "Belum selesai"));
        }
    }
}

// PROGRAM UTAMA
public class InteraksiObjek {
    
    public static void main(String[] args) {
        
        // Membuat objek Produk
        Produk produk1 = new Produk(101, "Buku Tulis", 5000, 50);
        Produk produk2 = new Produk(102, "Pensil", 2000, 100);
```

```java
/*
 * CONTOH MEDIA PLAYER LENGKAP (AUDIO + VIDEO)
 * Nama File: MediaPlayerApp.java
 */

package com.contoh.javafx;

import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.Slider;
import javafx.scene.layout.BorderPane;
import javafx.scene.layout.HBox;
import javafx.scene.layout.VBox;
import javafx.scene.media.Media;
import javafx.scene.media.MediaPlayer;
import javafx.scene.media.MediaView;
import javafx.stage.Stage;
import javafx.util.Duration;

import java.io.File;

public class MediaPlayerApp extends Application {
    
    private MediaPlayer mediaPlayer;
    private MediaView mediaView;
    private Slider timeSlider;
    private Slider volumeSlider;
    private Label timeLabel;
    private boolean isPlaying = false;
    
    @Override
    public void start(Stage primaryStage) {
        
        // 1. MEMUAT FILE MEDIA
        String path = new File("video/sample.mp4").toURI().toString();
        Media media = new Media(path);
        
        // 2. MEMBUAT MEDIAPLAYER DAN MEDIAVIEW
        mediaPlayer = new MediaPlayer(media);
        mediaView = new MediaView(mediaPlayer);
        
        // 3. MENGATUR UKURAN VIDEO
        mediaView.setFitWidth(600);
        mediaView.setFitHeight(400);
        mediaView.setPreserveRatio(true);
        
        // 4. MEMBUAT KONTROL
        Button btnPlay = new Button("▶");
        Button btnStop = new Button("⏹");
        Button btnLoop = new Button("🔁");
        
        timeSlider = new Slider(0, 1, 0);
        timeSlider.setPrefWidth(400);
        
        volumeSlider = new Slider(0, 1, 0.5);
        volumeSlider.setPrefWidth(100);
        
        timeLabel = new Label("00:00 / 00:00");
        
        // 5. MENGATUR EVENT
        btnPlay.setOnAction(e -> togglePlay());
        btnStop.setOnAction(e -> stopMedia());
        btnLoop.setOnAction(e -> toggleLoop());
        
        // 6. TRACKING PROGRESS
        mediaPlayer.currentTimeProperty().addListener((obs, oldTime, newTime) -> {
            if (mediaPlayer.getTotalDuration() != null) {
                double progress = newTime.toMillis() / mediaPlayer.getTotalDuration().toMillis();
                timeSlider.setValue(progress);
                timeLabel.setText(formatTime(newTime) + " / " + formatTime(mediaPlayer.getTotalDuration()));
            }
        });
        
        // 7. SEEK BAR
        timeSlider.setOnMouseClicked(e -> {
            double value = timeSlider.getValue();
            Duration duration = mediaPlayer.getTotalDuration();
            mediaPlayer.seek(duration.multiply(value));
        });
        
        // 8. VOLUME
        volumeSlider.valueProperty().addListener((obs, oldVal, newVal) -> {
            mediaPlayer.setVolume(newVal.doubleValue());
        });
        
        // 9. MENATA LAYOUT
        HBox controls = new HBox(10, 
            btnPlay, btnStop, btnLoop, 
            new Label("Volume:"), volumeSlider
        );
        controls.setStyle("-fx-padding: 10; -fx-alignment: center;");
        
        HBox timeline = new HBox(10, timeSlider, timeLabel);
        timeline.setStyle("-fx-padding: 10; -fx-alignment: center;");
        
        VBox bottomControls = new VBox(5, timeline, controls);
        
        BorderPane root = new BorderPane();
        root.setCenter(mediaView);
        root.setBottom(bottomControls);
        
        Scene scene = new Scene(root, 800, 600);
        
        primaryStage.setTitle("Media Player");
        primaryStage.setScene(scene);
        primaryStage.show();
    }
    
    private void togglePlay() {
        if (isPlaying) {
            mediaPlayer.pause();
            isPlaying = false;
        } else {
            mediaPlayer.play();
            isPlaying = true;
        }
    }
    
    private void stopMedia() {
        mediaPlayer.stop();
        mediaPlayer.seek(Duration.ZERO);
        isPlaying = false;
    }
    
    private void toggleLoop() {
        if (mediaPlayer.getCycleCount() == MediaPlayer.INDEFINITE) {
            mediaPlayer.setCycleCount(1);
        } else {
            mediaPlayer.setCycleCount(MediaPlayer.INDEFINITE);
        }
    }
    
    private String formatTime(Duration duration) {
        if (duration == null) return "00:00";
        int minutes = (int) duration.toMinutes();
        int seconds = (int) duration.toSeconds() % 60;
        return String.format("%02d:%02d", minutes, seconds);
    }
    
    @Override
    public void stop() {
        if (mediaPlayer != null) {
            mediaPlayer.stop();
            mediaPlayer.dispose();
        }
    }
    
    public static void main(String[] args) {
        launch(args);
    }
}
```

```java
            if (isNewInput) {
                displayField.setText(input);
                isNewInput = false;
            } else {
                displayField.setText(displayField.getText() + input);
            }
        }
        // Tombol operator (+, -, *, /)
        else if (input.matches("[+\\-*/]")) {
            firstNumber = Double.parseDouble(displayField.getText());
            operator = input;
            isNewInput = true;
        }
        // Tombol sama dengan (=)
        else if (input.equals("=")) {
            secondNumber = Double.parseDouble(displayField.getText());
            double result = calculate();
            displayField.setText(String.valueOf(result));
            isNewInput = true;
        }
        // Tombol clear (C)
        else if (input.equals("C")) {
            displayField.setText("");
            firstNumber = 0;
            secondNumber = 0;
            operator = "";
            isNewInput = true;
        }
    }
    
    private double calculate() {
        switch (operator) {
            case "+": return firstNumber + secondNumber;
            case "-": return firstNumber - secondNumber;
            case "*": return firstNumber * secondNumber;
            case "/": 
                if (secondNumber != 0) {
                    return firstNumber / secondNumber;
                } else {
                    JOptionPane.showMessageDialog(this, "Error: Division by zero!");
                    return 0;
                }
            default: return secondNumber;
        }
    }

        SwingUtilities.invokeLater(() -> new CalculatorUI());
    }
}
```

```java
package com.contoh.datamining;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.Map;

public class DataAnalysis {
    
    // 1. MENGHITUNG STATISTIK
    public static class Statistik {
        public double rataRata;
        public double min;
        public double max;
        public double standarDeviasi;
        
        public Statistik(double rataRata, double min, double max, double standarDeviasi) {
            this.rataRata = rataRata;
            this.min = min;
            this.max = max;
            this.standarDeviasi = standarDeviasi;
        }
        
        @Override
        public String toString() {
            return String.format("Rata-rata: %.2f, Min: %.2f, Max: %.2f, Std: %.2f", 
                               rataRata, min, max, standarDeviasi);
        }
    }
    
    public static Statistik hitungStatistik(ArrayList<Double> data) {
        if (data.isEmpty()) return null;
        
        double sum = 0;
        double min = data.get(0);
        double max = data.get(0);
        
        for (double d : data) {
            sum += d;
            if (d < min) min = d;
            if (d > max) max = d;
        }
        
        double rata = sum / data.size();
        
        // Menghitung standar deviasi
        double variance = 0;
        for (double d : data) {
            variance += Math.pow(d - rata, 2);
        }
        variance /= data.size();
        double std = Math.sqrt(variance);
        
        return new Statistik(rata, min, max, std);
    }
    
    // 2. FREKUENSI DATA
    public static Map<String, Integer> hitungFrekuensi(ArrayList<String> data) {
        Map<String, Integer> frekuensi = new HashMap<>();
        
        for (String item : data) {
            frekuensi.put(item, frekuensi.getOrDefault(item, 0) + 1);
        }
        
        return frekuensi;
    }
    
    // 3. SEGMENTASI KELOMPOK (Clustering sederhana)
    public static ArrayList<ArrayList<Double>> segmentasiData(ArrayList<Double> data, int jumlahCluster) {
        // Implementasi sederhana: cluster berdasarkan range
        ArrayList<ArrayList<Double>> clusters = new ArrayList<>();
        for (int i = 0; i < jumlahCluster; i++) {
            clusters.add(new ArrayList<>());
        }
        
        double min = data.get(0);
        double max = data.get(0);
        for (double d : data) {
            if (d < min) min = d;
            if (d > max) max = d;
        }
        
        double range = (max - min) / jumlahCluster;
        
        for (double d : data) {
            int index = (int) ((d - min) / range);
            if (index >= jumlahCluster) index = jumlahCluster - 1;
            clusters.get(index).add(d);
        }
        
        return clusters;
    }
```
